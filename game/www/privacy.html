隐私说明

「一年·房间」是一个运行在你设备上的静态网页应用。我们重视你的隐私。以下是完整的隐私说明：

1. 数据存储

本应用的所有数据——包括对话记录、存档、设置偏好——仅存储在你的设备本地（浏览器 localStorage）。没有数据被发送到任何服务器。没有数据被收集、分析或共享给任何第三方。

2. 我们收集什么

什么都不收集。本应用没有后端服务器、没有数据库、没有用户账户系统、没有分析工具。你在一台机器（RC-7）面前说的所有话——只存在于你的设备上。

3. 如何清除你的数据

清除浏览器数据（设置→清除浏览数据→选择"Cookie和站点数据"）即可永久删除所有本地存储的对话记录和存档。卸载PWA也会清除数据。

4. AI模式（未来功能）

如果未来启用AI对话模式，你需要提供自己的LLM API密钥。你的对话内容将被发送到对应的AI服务商（如DeepSeek/OpenAI）进行处理。本应用本身不存储或中转这些对话。

5. 联系我们

如果你有任何隐私方面的疑虑，可以通过 GitHub Issues 联系我们。
