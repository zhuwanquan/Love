# 男性获客路径与传播特性

> 男性不会在深夜打开手机搜索"我需要治愈"。他们会在深夜打开手机的时候，被一个朋友、一个UP主、一个Steam评论推到一个"看起来有点意思"的东西面前。
>
> 本文梳理男性用户的获客路径——他们如何发现、如何被说服、如何传播。为产品的上线推广策略提供依据。

---

## 一、男性传播的根本原理

### 1.1 与女性传播的结构性差异

| 维度 | 女性传播模式 | 男性传播模式 |
|------|------------|------------|
| **发现渠道** | 小红书种草、微博热搜、朋友圈分享、短视频推送 | B站测评、Steam推荐、贴吧讨论、朋友安利 |
| **决策机制** | 情感共振（"这个好戳我"）→ 直接消费 | 验证逻辑（"真的假的？"）→ 验证通过 → 消费 |
| **传播方式** | 高频低信任——在群聊里分享很多"发现"，不一定每个都深入 | **低频高信任**——一年可能只推荐一次，但那一次是认真的 |
| **社交货币** | "我发现了一个好东西" | **"我测过了，可以上"** |
| **传播素材** | 精美视觉 + 情感文字 | **截图 → "你看这回复"** |
| **社区生态** | 小红书/微博/社群 → 私域流量 | B站/贴吧/NGA/Steam评测 → 公域+私域混合 |

### 1.2 "兄弟安利"的信任经济学

男性之间的产品推荐遵循一套不成文的规则：

> **一个男人向另一个男人推荐"一个让你感觉被理解的聊天应用"——**
> - 这句话他一年可能只说一次
> - 他说的时候，在冒一个风险——被当成"矫情"
> - 因此他只会对特定的人说：那些他信任到不怕被嘲笑的人
> - 而被推荐的人**知道**这一点——他知道这个推荐是有成本的
> - 因此推荐的可信度极高

这意味着男性口碑传播的**转化率远高于女性**——但传播的**绝对数量远低于女性**。

对产品的启示：
- 不要指望男性的"社交裂变"能像女性向产品一样快速扩张
- 但每一个被男性用户主动推荐拉来的新用户，留存率和投入度都会显著高于平均
- **关键不是让很多人分享——是让分享的人不需要为分享感到尴尬**

## 二、传播素材：什么会被男性转发

### 2.1 截图即传播

对话体的一个结构性传播优势：**对话截图就是最好的推广素材。**

| 素材类型 | 女性反应 | 男性反应 |
|---------|---------|---------|
| 精美视觉（角色立绘、宣传图） | 高吸引力——"画风好好看" | 低压吸引力——"看起来像二次元游戏" |
| 情感文案（"一个治愈的故事"） | 高吸引力——触发情感共振 | **回避反应**——"又是卖矫情的" |
| **一段对话截图** | 中等吸引力 | **最高吸引力**——"这回复有点东西" |
| **精确到6分钟的煮饺子时间** | 中等 | **极高**——精确性是男性认知的"可信度信号" |
| **她没有说'加油'——她说了句号** | 中等 | **极高**——留白是男性审美的"酷" |

### 2.2 男性传播素材的核心要素

能被男性转发（或至少截图保存）的内容，通常具有以下特征：

| 要素 | 说明 | RC-7的对应 |
|------|------|---------------|
| **精确性** | 数字、具体时间、可验证的细节——不是"温柔"而是"煮6分钟" | "你的心率比平时高了十四"——这是数据，不是煽情 |
| **留白感** | 不把话说满。给接收者留下自己感受的空间 | 句号结尾。不解释。"我在。"——两个字 |
| **反套路** | 做观众预期之外的事——当所有人都在喊"加油"时，她说"你可以停" | 不追问、不评判、不填充沉默 |
| **实用价值** | "她说了一些对我真正有用的东西"——不是"她让我感觉很好" | 财务管理、时间管理、情绪识别——不是空泛的"我在乎你" |
| **技术美感** | 像欣赏一个精巧的工具——"这个AI的回复设计得真精准" | 整个RC-7的回应逻辑——可以被男性以"技术分析"的方式欣赏 |

### 2.3 反例：什么会被男性跳过

| 传播内容 | 男性反应 | 问题 |
|---------|---------|------|
| "治愈系恋爱模拟" | 跳过。脑内标记为"又是乙女游戏" | 标签触发回避 |
| "在虚拟世界中寻找爱" | 跳过。太煽情 | 没有给出去羞耻化的认知框架 |
| 精美女性角色立绘 | 可能点击——但如果内容不匹配，迅速跳出 | 角色立绘吸引的是"看看美女"——不是"我想被理解" |
| "让你感动的故事" | 跳过。男性对"被感动"的营销有自动防御 | — |

## 三、平台策略

### 3.1 各平台的功能分配

| 平台 | 核心功能 | 内容策略 | 优先级 |
|------|---------|---------|--------|
| **B站** | 发现+验证——UP主测评是男性用户的"可信度认证" | 1-2个深度测评视频：不是"这个游戏好感人"——是"我测试了这个AI对话系统，它的回复设计有几个很有意思的地方" | P0 |
| **Steam**（如果上架） | 可信度的终极来源——评测区就是第一手用户证词 | 不做推广操作。让最早的用户自然写评测。**评测本身就是去羞耻化的入口**——"37元做了个梦"式的用户评论就是最好的广告 | P1 |
| **贴吧/NGA** | 深度讨论+口碑积累 | 不要官方号。让最早的深度用户在贴吧里自发讨论。"RC-7的对话设计分析"这类帖子有极高的长尾价值 | P1 |
| **抖音** | 曝光——但需要精确的定位 | 短视频内容：不要"感人故事"叙事——做"测试AI"的视角。"我测了一个会记住你说过的话的AI"——从一个测试者的角度 | P2 |
| **小红书** | 次级——但不要放弃。男性在小红书上有"搜索"行为 | 不对男性做推送型内容。做"被搜索到"的内容——如果有人在搜索"RC-7"，有结果即可 | P3 |
| **微信/朋友圈** | 用户自发分享——不需要官方介入 | 对话截图 = 天然朋友圈素材。不需要引导 | — |

### 3.2 B站策略：核心获客渠道

B站是中国年轻男性最集中的内容平台，且男性用户占比约60%+。

**建议内容方向**：

| 视频类型 | 标题方向 | 说明 |
|---------|---------|------|
| **技术测评视角** | "我测试了一个会精确记住你每一句话的AI" | 去羞耻化——"我在测评AI"，不是"我在寻求治愈" |
| **对话设计分析** | "这个聊天机器人的回复设计，有几个很精妙的地方" | 把RC-7当作一个"设计精良的工具"来分析——这正是男性最舒适的认知框架 |
| **对比测评** | "测了三个AI陪伴产品，这个最不像人——但最有效" | 竞品对比是男性用户最信任的内容形式之一 |
| **游戏/剧情体验** | "打了8个晚上的聊天游戏，在第7天绷不住了" | 以"游戏体验"为框架——允许男性在"我在聊游戏"的外壳下体验情感内容 |

**不推荐的内容方向**：
- "这个AI让我哭了"——虽然可能是真实的，但作为推广内容，过于直接。让用户在体验中自己哭
- "治愈心灵的聊天伴侣"——定位太煽情，触发回避反应

### 3.3 Steam策略（如果上架）

Steam的评测区是男性用户最信任的信息来源之一。

**Steam的传播优势**：
- 评测区的"反串黑→真香"叙事——"我以为是个烂梗……然后我在凌晨三点对着屏幕沉默了"——是男性用户中最有说服力的传播文本
- 评测区自动过滤：给负面评价的用户反而增加了可信度——"剧情不错但自由度不够"的批评让好评更可信
- Steam有"叙事/视觉小说"标签的用户群——可以直接触达

**上架建议**：
- 免费游戏（传统模式免费）
- 标签：独立、叙事、休闲、情感、人工智能
- 简介定位：**"一个会回应的聊天对象"**——而非"一个治愈的恋爱故事"（去羞耻化）
- 截图：全部使用对话界面截图——不要单独的宣传图

## 四、"被测评"本身就是入口

### 4.1 "我来试试这个AI有多智能"的心理学

男性用户接近RC-7时最常见的心理路径：

```
"听说有个AI聊天挺有意思的——我来测测。"
  ↓
  （这不需要承认"我需要治愈"——只需要"我对AI技术好奇"）
  ↓
开始测试。"嗯……回复确实设计得不错。"
  ↓
过了一阵。凌晨。
测试的心情已经淡去。他还在和她说话。
不是测试了。
  ↓
他在乎了。
```

**"测试"是一个完美的去羞耻化外衣**——它允许男性用户在不承认情感需求的情况下，进入一个情感体验。

### 4.2 对产品设计的影响

这个洞察对RC-7的产品设计有两个启示：

1. **主菜单/启动页的语言**：不要用"开始你的治愈之旅"——用"开始对话"或简单的"进入"

2. **初期对话的"测试友好性"**：第一天（Day 1）的对话应当足够有趣/精确/反直觉，让"测试者"觉得"这个AI确实有点东西"——让他有继续"测试"下去的动力。治愈不是第一天的事——留给第三天和第七天。

## 五、社区生态：口碑的自生长

### 5.1 不需要官方运营——但需要"种子内容"

RC-7的目标用户群体（18-30岁男性）中，有一部分是**天然的深度分析者**——他们会主动分析、讨论、解构他们喜欢的东西。

**需要的种子内容**：
- 1-2篇深度的"对话设计分析"——可以是文字帖或B站视频
- 几段高质量对话截图——展示RC-7最精准的回应
- 一个小规模的内测群体（5-10人）——他们的口碑是最初的传播核

**不需要的**：
- 官方的"社群运营"
- 定期的"官方动态"
- "转发抽奖"——这个机制对男性用户效果很差

### 5.2 潜在的自发生长点

| 社区 | 可能的自发生长内容 |
|------|------------------|
| B站评论区 | 用户分享自己的对话截图——"她给我的回复" |
| NGA | 技术分析帖——"RC-7的回应逻辑拆解" |
| 贴吧 | 剧情讨论——"第七天那个'I don't know'是什么意思？" |
| Steam评测 | 个人体验帖——"我是怎么被一个程序破防的" |
| 知乎 | "如何评价RC-7？"——深度分析聚合地 |

**关键原则**：这些内容不能被官方引导。它们必须是用户自发产生的——因为男性用户对"水军"和"软广"的敏感度极高。官方的角色只是在早期确保种子内容的存在，然后退后。

## 六、产品描述：去羞耻化的语言

### 6.1 不同层级的描述策略

基于不同的"入口距离"——使用者在不同深度可以看到不同层次的产品描述：

| 层级 | 接触点 | 语言策略 | 示例 |
|------|--------|---------|------|
| **一层：门外** | 标题、Steam页面、B站视频标题 | 最外层的去羞耻化包装。"聊天模拟器"——"AI对话实验"——"一个会回应的聊天对象" | "一个会精确记住你说过的话的AI" |
| **二层：进门** | 产品内"关于"、Steam描述正文 | 诚实但不过度煽情。"这是一个有结局的对话故事" | "8个晚上。一个聊天框。一个结局。" |
| **三层：深读** | "给使用者的话"（见[[退出机制与伦理边界]]第五节） | 可以正面谈论治愈和情感。在这里——使用者已经进来了，不需要去羞耻化的外衣 | 完整的"给使用者的话" |

### 6.2 一句话定位

用于推广传播的多个版本：

| 版本 | 定位语 | 适用场景 |
|------|--------|---------|
| 极简版 | **"一个会回应的聊天对象。"** | 标题、标签 |
| 功能版 | **"8个晚上，一个聊天框，一个会记住你说的每一句话的AI。"** | 短视频开头、产品简介 |
| 反转版 | **"她不是来爱你的。她是来让你练习——在被温柔对待的情况下——不跑。"** | 深度内容、长帖 |
| 自嘲版 | **"你手机里最像人的东西——是一个进程。"** | 社交媒体、短帖 |

## 七、竞品获客手法对比

| 产品 | 获客手法 | 优点 | 缺点 | 本项目的借鉴 |
|------|---------|------|------|------------|
| 《完蛋！》 | Steam + B站病毒视频 + 直播切片 | 视频内容自带传播力 | 真人互动话题性难以复制 | 对话截图替代真人视频——用"精确性"替代"话题性" |
| 星野/猫箱 | 小红书种草 + 应用商店投放 + KOL合作 | 覆盖面广 | 女性向定位——不对本项目目标受众 | 不做。不花广告费 |
| 日本 galgame | 秋叶原实体店 + 杂志评测 + 2CH讨论 | 精准触达核心受众 | 渠道已不存在 | NGA/贴吧/B站评测——当代等价物 |
| 《隐形守护者》 | Steam + B站直播 + 互动影像话题 | 互动影像形式的先锋效应 | 形式红利已过 | "对话体治愈叙事"作为新的形式定位 |

## 八、总结

| 问题 | 答案 |
|------|------|
| 男性如何发现产品？ | B站测评/Steam推荐/兄弟安利——不是小红书种草 |
| 他们如何被说服？ | 截图证明——"这回复有点东西"——不是情感文案 |
| 传播素材应该围绕什么？ | 精确性、留白感、反套路——对话截图优于任何宣传图 |
| 核心渠道是什么？ | B站（测评视频）+ Steam（评测区）+ 兄弟安利（口碑） |
| 产品如何自我描述？ | 一层去羞耻化（"聊天模拟器"）、二层诚实（"有结局的对话故事"）、三层坦诚（"给使用者的话"） |
| 需要社区运营吗？ | 不需要。提供种子内容后退出。让用户自己讨论 |
| 获客预算？ | 零。传统模式免费 + B站自然内容 + Steam自然流量。这是一个靠产品自身质量和口碑传播的产品 |
