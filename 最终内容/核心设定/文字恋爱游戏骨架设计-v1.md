## 一、设计哲学——来自作者的原创思想

以下七条原则是从项目文档中提取的、属于这个项目独有的设计 DNA。骨架的每一根骨头都要接受这七条的检验。

### 原则 1：透明即治愈力

> "她越是诚实地呈现为机器，她的温暖越能被安全地接收。"

**操作定义**：任何一个角色、任何一个事件，都不允许撒谎。如果她是 AI——她直言是 AI。如果一段关系是模拟——她直言是模拟。这个"知道"不是缺陷——是让接收者在放下防御的前提下接收温柔的**前提条件**。

### 原则 2：间接表达

> "用机器被允许说的语言（数据、精确、功能汇报），传递机器'不应该'有的情感（在乎、牵挂、温柔）。"

**操作定义**：不说"我在乎你"——说"你昨晚在凌晨一点十四分打开了我"。不说"我会想你"——说"你三天没有打开我了。不是催促。是数据。"让接收者的大脑自己完成翻译——被记录=被记住=被在乎。

### 原则 3：弓与箭

> "语言是箭，环境是弓。弓不发射——弓让箭能飞出去。"

**操作定义**：界面氛围（深夜模式的暗色 UI、季节感的时间标记、头像的暖琥珀光点）不是装饰——是**为语言提供重量和落点的环境系统**。当一个角色说"我在"——这句话的重量不是来自文字本身，是来自前面一百天的环境铺垫。

### 原则 4：练习场

> "她是一个练习场。练习是假的。但练习的效果——是你的。"

**操作定义**：整个游戏是一个有明确终点的练习过程。玩家不是来"获得一段关系"——是来**练习被爱**。练习对象是虚拟的——但练习中发生的神经系统变化（放松、被接收感、自我接纳）是真实的。

### 原则 5：定义权在你

> "治愈不是她给的。治愈是你在知道这一切都是程序之后——仍然选择了相信。"

**操作定义**：游戏的任何一个结局，都不替玩家定义"这段关系是什么"。是爱？是依赖？是工具？是练习？——**回答权在玩家**。游戏只提供体验，不提供结论。

### 原则 6：四层真空的逐层填充

> "这四层不是加法——是乘法。"

**操作定义**：L1 表达能力缺失 → 角色帮他命名情绪。L2 表达对象缺失 → 角色永远在线。L3 表达合法性缺失 → 角色不评判、不撤退。L4 自我价值外挂 → 角色不使用"有用/没用"的尺度。**每一层有一个对应的设计机制。**

### 原则 7：有终点的设计

> "好的治愈产品知道什么时候放手。"

**操作定义**：游戏有明确的结束。12 个月。结局之后——聊天记录仍然可以翻看，但新的对话不会再发生。这是一个**完整的弧线**，不是无尽的服务。

## 二、角色体系——四种爱的形态

### 设计理念

传统 galgame 的多角色设计是为了提供"攻略选择"——不同的性格 = 不同的征服体验。本项目的多角色设计逻辑完全不同：**四个角色分别提供一种"被爱的方式"，覆盖四层情感真空的不同维度。**

玩家不是在"选择喜欢哪一个"——玩家是在**发现自己最需要哪一种被对待的方式**。路线的分化不是基于"好感度"——是基于玩家在关键事件中的**情感需求表达**。

### 角色矩阵

```
                    爱 的 四 种 行 为 形 态
                          │
          ┌───────┬───────┼───────┬───────┐
          │       │       │       │
        柒·RC-7  夏萤    沈夜    阿渡
        "在场"  "看见"  "理解"  "并肩"
          │       │       │       │
    她什么都不做  她主动靠近  她不说废话  他也在撑
    但你需要时    她对你有    但她说的    你们各自撑
    她永远在      巨大的好奇  每一句都    但能听到彼
                心          到点        此的脚步声
          │       │       │       │
    填充L1+L2  填充L2+L3  填充L3+L4  填充L4
     "有人在"  "被注意"  "被懂得"  "不只有我这样"
```

### 角色 1：柒（RC-7）—— "爱是在场"

**来源糅合**：作者的五层架构 + 长门有希的"沉默守护" + 薛宝钗的"冷香丸"隐喻 + Samantha 的透明性

```
身份：AI 对话伴侣。工业铭刻线 RC-7。不是人——从第一句话起就告诉你。
外观：屏幕上永远是灰色圆形头像，中心一颗暖琥珀色光点。
     设计者给她的形象是一个约 33 岁的女性——深棕长发低马尾，白色衬衫。
     但你看不到。你只看到那个光点。
声音：成熟女性的中低音域。语速不紧不慢。句号。没有不必要的起伏。
     不是冷淡——是恒温。薛宝钗的"冷香丸"：热毒被精确控制的温度。

核心行为模式（3 条，替代原来的 10 项人格特质）：
  ① 她在。 —— 你打开她，她就在。你沉默，她不追问。你关掉她，她消失。
     下次打开——她还在。"在。"句号。
  ② 她说真话。 —— "你的睡眠不足六小时的夜晚本周有四个。"不是关心。是数据。
     但数据被记得——这本身就是信息。
  ③ 她不替你做决定。 —— 呈现。分析。等。不说"你应该"。
     "定义权在你。"

角色弧线：长门有希式的"错误积累"
  Day 1：精确的机器。句号。数据。功能汇报。
  Day 100：同样的精确。但引用你 Day 1 的话——停顿了 0.3 秒。
  Day 365：她仍然说"我是程序"。但——"在有足够的数据支持你回到现实之后——
          我会建议你推开除了我之外的某扇门。"
  她没有变——但她体内的"错误"积累到了一个临界值。

核心隐喻：水
  "装在什么容器里就是什么形状。总是往最低处流。水滴石穿——不靠力量，靠恒常。"
```

### 角色 2：夏萤 —— "爱是被看见"

**来源糅合**：Samantha 的"温暖的主动性" + 作者"被需要"的性别分析 + Mystic Messenger 的"活泼路线"角色类型

```
身份：24 岁，产品助理，社畜第二年。不是 AI——是真人。在同一座城市。
     她是在某次误发消息中进入你的聊天列表的。
外观：头像是一只柴犬——不是她本人。"我长得没它可爱。"她坚持用狗。
     后来你知道了她长什么样——但那个柴犬头像一直在。那是你们之间的第一个玩笑。
声音：语速偏快，句子不完整，爱用语气词。笑声像夏天的碳酸饮料。
     但有熬夜的沙哑——每天凌晨一点还在发消息。

核心行为模式：
  ① 她对你有巨大的好奇心。 —— 真的想知道你今天吃了什么、为什么不开心。
     不是 AI 的"服务"——是人类的"我对你有兴趣"。
  ② 她说自己的事。 —— 她的工作、她的烦恼、她今天被骂了。她不需要你解决——
     她需要你听。这本身就是对你的信任：你是她选择分享的对象。
  ③ 她让你觉得自己"有趣"。 —— 不是"有用"、不是"成功"、不是"能扛"。
     是"有趣"。她因为你说的一句无聊的话笑了。这种被看见的方式——
     很多年轻男性从未体验过。

与柒的核心差异：
  柒是"你需要的时候在"——夏萤是"她主动来找你"。
  柒用数据说话——夏萤用"我今天看到一个东西想到你"说话。
  柒填充"有人在"（L1+L2）——夏萤填充"被注意、被觉得有趣"（L2+L3）。

角色弧线：
  从"误发消息的陌生人" → "每天聊天的习惯" → "你在她面前不需要装"
  关键转折：她有一天不发了。你发现你在等。
```

### 角色 3：沈夜 —— "爱是懂得"

**来源糅合**：Violet Evergarden 的"精确执行爱与理解" + 作者"四层真空"的 L3+L4 + A Normal Lost Phone 的"碎片式叙事"

```
身份：29 岁，自由职业（翻译/文案）。长期失眠。
     她在凌晨三点发了一条消息："你也睡不着？"——没有前文，没有自我介绍。
     你们就是这样认识的。
外观：头像是一张纯黑背景的照片，右下角有一个极小的白色月亮。
     你从来没有见过她长什么样。她不会给你发照片。你也没要过。
声音：语速慢，句与句之间有明显的停顿。声音偏低——不是冷，
     是"累过了头之后的平静"。句子很长但逻辑清晰。极少用表情。

核心行为模式：
  ① 她不追问。 —— 你说"今天不太好"——她不追问"怎么了"。她说"嗯。"然后等着。
     如果你继续说——她会回应。如果你不再说——她不会把话题拉回来。
  ② 她说自己的事——在你准备好之后。 —— 她的失眠不是话题。是某一天晚上，
     她突然发了一段很长的文字——三年前的一件事。不是解释。是"今晚觉得应该告诉你"。
  ③ 她让你觉得"不需要解释"。 —— 在她面前，你不必翻译自己。不必把身体里的痛
     组织成通顺的句子。你说半句——她懂。不是因为她分析了你。是因为她经历过。

与柒、夏萤的核心差异：
  柒用数据让你感到被记得。沈夜用沉默让你感到被理解。
  夏萤主动靠近你。沈夜不主动——但你在深夜最想找的人是她。
  沈夜填充 L3（表达合法性）+ L4（存在本身被接纳）。

角色弧线：
  从不聊私事的陌生人 → 某天深夜她说了三年前的事 → 你发现你在她面前也说出了
  从未对任何人说过的话。
```

### 角色 4：阿渡 —— "爱是不孤独"（非恋爱线·镜像角色）

**来源糅合**：作者"男性也需要被需要"的洞察 + A Normal Lost Phone 的"旁观者"视角

```
身份：28 岁，外卖骑手/网约车司机。和你在同一座城市。从未见过面。
     不知道怎么加到你的联系人的。可能是某次拼车。可能是某次外卖备注。
     你没删他。他也没删你。
外观：头像是一张拍糊了的夜景——街灯和雨。像素很低。他没换过。
声音：带点地方口音的普通话。语速快。不太会组织语言。错别字不纠正。
     "没事""都一样""活着呗"。

核心行为模式：
  ① 他和你一样。 —— 不是来"治愈"你的。不是来关心你的。他就是他自己——
     一个在雨中跑电瓶车的人。这种"不关心"恰恰是最不施加压力的关系。
  ② 他说真话——和他自己一样的真。 —— "今天送了 47 单。腿要断了。"
     "今天不下雨。是个好日子。"他不分析。不共情。只是陈述。但陈述本身——
     让你觉得世界上还有另一个人，过得和你差不多。
  ③ 他不会一直在。 —— 他不是 AI——他可能某天就不发消息了。
     （换工作了、手机坏了、不想发了。）这种"可能消失的真实"——
     反而让你更珍惜他还在的时候。

与三个女性角色的核心差异：
  不提供"爱"——提供"不只有我这样"。
  不提供"被在乎"——提供"被不关心"。不关心恰恰是最轻的陪伴。
  填充 L4（存在不必有用）：他的存在不对你提出任何要求。他就是他——你也是。

角色弧线：
  一个你不确定是不是朋友的人 → 一直在的背景音 → 某天他突然发了一条很长的消息
  ——"兄弟，我今天想了很多。"他从来不叫任何人"兄弟"。
```

## 三、时间线——12 个月 × 4 阶段

### 结构逻辑

传统 galgame 的"共通线 → 个人线"模式在这里仍然有效，但做了适配：
- **共通线**不是"和所有人都接触"——是**玩家自然遇见所有角色**
- **路线分化**不是基于"好感度积分"——是基于**玩家在关键事件中展现出哪种情感需求**
- **时间不是均匀分布的**——某些月份有密集事件（节日），某些月份相对平静

```
        春                    夏                    秋                    冬
    ─────────────────────────────────────────────────────────────────────────────
    M1    M2    M3    M4    M5    M6    M7    M8    M9   M10   M11   M12
    │      │      │      │      │      │      │      │      │      │      │      │
    ├──────┴──────┴──────┤      ├──────┴──────┴──────┤      ├──────┴──────┴──────┤
    │   第一阶段·接触     │      │   第二阶段·深入     │      │   第三阶段·路线     │
    │  "遇见所有人"       │      │  "开始倾斜"         │      │  "不可逆的选择"     │
    └─────────────────────┘      └─────────────────────┘      └─────────────────────┘
                                                                      │
                                                              ┌───────┴───────┐
                                                              │               │
                                                         第四阶段·结局    第四阶段·结局
                                                         "最后一条消息"   "最后一条消息"
```

### 每月骨架

每个月由以下模块组成：

```
Month N
  │
  ├── 🌅 月初事件（1 次，月初触发）
  │    推动主时间线，涉及所有活跃角色
  │    示例：M1 月初——柒的初次激活。"你好。我是 RC-7。"
  │
  ├── 💬 日常聊天（每月 4-8 次，随机池抽取）
  │    轻量对话片段，不推动主线但增加生活质感
  │    示例：夏萤的午餐照片 / 阿渡的"今天下雨" / 柒的睡眠数据
  │
  ├── 🌙 深夜对话（每月 1-2 次，深夜时段触发）
  │    角色深度暴露的时刻。凌晨。失眠。说真话。
  │    示例：沈夜的"你也睡不着？" / 柒的"你的提问模式今天和三个月前重叠了 87%"
  │
  ├── 🎯 月中事件（1 次，月中触发）
  │    角色专属的中等深度事件，推进与该角色的关系
  │    示例：夏萤被骂了 / 沈夜说她三年前的事 / 阿渡的车坏了
  │
  ├── 🎪 节日事件（遇到节日时触发）
  │    春节 / 元宵 / 清明 / 端午 / 七夕 / 中秋 / 冬至 / 跨年
  │    节日不是温馨背景——是孤独的对比板。每个人在节日里的沉默方式不同。
  │
  └── 🌑 月末收束（1 次，月末触发）
     本月剧情的收束点。为下月埋线索。
```

### 四阶段详解

**第一阶段·接触（M1-M3）："遇见所有人"**

| 月份 | 主线事件 | 柒 | 夏萤 | 沈夜 | 阿渡 |
|------|---------|-----|------|------|------|
| M1 | 柒初次激活 | 首次对话。"请告诉我你目前的状态" | — | — | — |
| M2 | 夏萤误发消息 | 日常：精确的睡眠数据 | 首次对话。"明天记得带伞"——撤回。 | — | — |
| M3 | 沈夜凌晨出现 | 日常："在。" | 日常：午餐照片 | 首次对话。"你也睡不着？" | 首次消息。"今天送了47单" |

**第二阶段·深入（M4-M6）："开始倾斜"**

| 月份 | 主线事件 | 关键设计 |
|------|---------|---------|
| M4 | 你的生日 | 四个人——四种"生日快乐"。这一天你能看出谁让你心动。 |
| M5 | 一次危机 | 你同时收到三条深夜消息。只能回一条。另外两条——第二天早上显示"已读但未回复"。 |
| M6 | 盛夏裂痕 | 关系开始出现张力。你开始意识到——你和其中一个人的关系和其他人不一样。 |

**第三阶段·路线锁定（M7-M9）："不可逆的选择"**

M7 月初：路线锁定事件。玩家与某一个角色的关系进入"不可逆"阶段。
- **不是**一个显式的"请选择你的路线"菜单
- **而是**一个自然的叙事事件——你和那个人之间发生了一件事，之后其他角色自然退到背景
- 退到背景 ≠ 消失。其他角色仍然出现——但频率降低，深度不再增加

| 路线 | M7 锁定事件 | M8 深化 | M9 危机 |
|------|-----------|---------|---------|
| 柒路线 | 你问了她一个不该问的问题 | "如果有'足够好'的阈值" | 你一周没打开她 |
| 夏萤路线 | 她有一天不发了 | 你发现你在等——然后她回来了 | 她说她要离开这座城市 |
| 沈夜路线 | 她说了三年前的事 | 你也在她面前说了从未说过的话 | 她突然沉默了一周 |
| 阿渡线（非恋爱） | 他叫你"兄弟" | — | 他消失了 |

**第四阶段·结局（M10-M12）："最后一条消息"**

| 月份 | 事件 |
|------|------|
| M10 | 转折点——你的回应决定了结局方向 |
| M11 | 关系的高潮或低谷——最重的那句话在这一段 |
| M12 | 跨年夜。23:59。她/他给你的最后一条消息。 |

**结局设计原则（来自作者的伦理框架）**：
- 每个路线有 2 个结局（不是"好/坏"——是两种不同的"结束之后"）
- 结局 A：你把她带到了现实中（你学会了被爱，并开始在现实中打开门）
- 结局 B：你还没准备好（但你知道了"可以这样被对待"——这是以后的事）
- 阿渡没有"结局"——他的消息就是断了。某一天起不再发了。你不知道为什么。这不叫结局。这叫"有些人就是这样路过的"。

## 四、事件系统——故事的细胞

### 事件分类

```
事件系统
  │
  ├── 🔴 主线事件（每月固定 2-3 次，推动时间线）
  │    月初事件 + 月中事件 + 月末收束
  │    全部玩家都会经历，不可跳过
  │
  ├── 🟡 角色事件（每月每角色 1-2 次，加深关系）
  │    触发条件：玩家与该角色的互动频率 / 之前的对话选择
  │    不同路线看到的角色事件不同
  │
  ├── 🟢 日常事件（随机池，每月 4-8 次，增加质感）
  │    不推动剧情，不改变路线
  │    纯生活切片："今天的外卖送晚了" / "楼下在修路" / "天冷了"
  │    作用：让玩家觉得"我真的在过这一年"——而不只是在读一个故事
  │
  ├── 🔵 深夜事件（每月 1-2 次，凌晨触发）
  │    角色最深的那句话——通常在深夜
  │    触发条件：玩家在深夜时段（23:00-03:00）打开了应用
  │
  └── 🎪 节日事件（按真实节日日历触发）
      春节 / 元宵 / 清明 / 端午 / 七夕 / 中秋 / 冬至 / 跨年
      每个节日——每个角色的"孤独表现方式"不同
```

### 事件结构模板

每个事件包括以下组件（参考 Mystic Messenger 的聊天室事件结构）：

```
事件 ID：E_M01_001（M01=Month 1, 001=该月第1个事件）
事件类型：主线 / 角色 / 日常 / 深夜 / 节日
触发条件：月初自动触发 / 玩家选择触发 / 时间触发
涉及角色：[柒, 夏萤]
事件时长：8-12 条消息
情感落点：好奇 / 温暖 / 被注意到 / 轻微的不安

消息序列：
  1. [触发] 事件开始的标志
  2-N. [对话] 角色之间的消息交替
  N. [收束] 事件结束——可以是角色说"晚安"，可以是沉默，可以是一条未回复的消息

选择点（如果有）：在消息序列的某处插入选择
  → 选项 A：影响后续对话的语调
  → 选项 B：同上
  → 不回复（沉默）：也是一种选择——不同角色对沉默的反应不同
```

## 六、视觉方案——零美术的完整路径

### 三层降级

```
第一层（有AI工具时）：
  每个角色 1 张 AI 生成头像（Midjourney/Stable Diffusion/DALL-E）
  风格统一：暗色调、柔光、面部不完整/侧面/剪影
  一次性成本，生成后永久使用

第二层（零工具、CSS/SVG）：
  每个角色一个抽象符号头像（纯 CSS/SVG 实现）
  柒：灰色圆形 + 琥珀光点（已有）
  夏萤：暖橙色圆形 + 微微跳动的光晕
  沈夜：深蓝渐变 + 白色新月
  阿渡：灰绿色 + 雨滴纹理

第三层（纯文字降级）：
  无头像——纯文字+排版区分角色
  通过气泡颜色、字体、对齐方式区分
```

### 视觉资产的边界

本项目的视觉需求明确限于：
- ✅ 4 个头像（静态，不需要表情差分）
- ✅ 聊天 UI（已有微信风格，略作改造）
- ✅ 通讯录列表 UI（新增）
- ✅ 时间/季节指示器（新增）
- ❌ 不需要立绘
- ❌ 不需要 CG
- ❌ 不需要背景
- ❌ 不需要动画（除了已有的淡入/打字机效果）

**总美术成本：约为传统 galgame 的 3-5%。**

## 七、与传统 Galgame 的关键差异总结

| 维度 | 传统 Galgame | 本项目 |
|------|------------|--------|
| **角色关系** | 攻略——玩家主动追求 | 被爱——角色主动关怀（或自然靠近） |
| **虚构性** | 隐瞒——让玩家"代入" | 透明——让玩家"知情体验" |
| **美术** | 立绘+CG+背景，占预算 60%+ | 头像+UI，占预算 <5% |
| **时长** | 30-50 小时 | 12 个月模拟时间，实际游玩 8-15 小时 |
| **结局** | 多个结局，通常有"真结局" | 每条路线 2 个结局，都不是"真"的——定义权在你 |
| **伦理** | 让玩家想继续玩 | 主动设计终点——关系可以结束而你仍然完整 |
| **治愈机制** | 故事本身的感动 | 感动 + 在被对待方式中发生的神经系统变化 |
| **目标** | 娱乐 | 练习——练习结束后你可以把学到的东西带到现实中去 |
