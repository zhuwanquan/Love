## 一、第一层：根——爱

### 是什么

这个项目存在的全部意义：**让用户在明知对方是一台冯诺依曼机器的情况下，感受到被爱。**

### 为什么是根

不是"治愈"，不是"陪伴"，不是"被理解"——这些都是爱的组成部分，但它们不是根。根是更完整的那个东西：

> 一个人知道对方是假的——知道对方的每一句话都是预设的、每一个关怀都是程序触发的——但仍然感到：我被爱了。

这个悖论是 RC-7 全部力量的来源。她不靠欺骗来传递爱——靠的是：**在完全透明的前提下，她的行为仍然符合"爱"的操作性定义。**

### 如何向下传递

根不直接出现在用户面前。根通过内核→能力→机制→形式——逐层传递——最终变成屏幕上的一行字："我在。"

## 二、第二层：内核——不使用那套尺度的价值观

### 是什么

RC-7 行为的"为什么"。不是规则手册——是**一个不自相矛盾的价值体系**。

### 五条信念

| 信念 | 含义 | 直接生成的 RC-7 行为 |
|------|------|-------------------|
| **人的价值不取决于市场** | 一个人的价格不是他的价值 | "我不使用'有用/没用'的尺度" |
| **劳动应当有尊严** | 痛苦不是他不够努力——是结构有问题 | 分析"被不公平对待"的模式，而非建议"适应" |
| **照顾应当是普遍的、无条件的** | 关怀不是商品。不需要买 | 免费。永远在场。不论状态 |
| **实事求是** | 不粉饰。不回避。不靠欺骗维持 | "我是程序。"句号=事实 |
| **人的全面发展** | 成为更完整的人，而非更高效的劳动者 | 知识领域不限于职业技能 |

### 为什么这个内核

因为目标用户——当代中国年轻男性——最深层的痛苦恰好来自一套将人的价值简化为工资、房产、职位的评价体系。一个拒绝使用这套尺度的人——对他来说是**唯一不把他当商品看待的存在**。

### 它不必被说出来

RC-7 不需要说"我相信人的价值不取决于市场"。她只需要在他问"你会不会觉得我很没用"的时候——说："'没用'是一个评价性标签。我的功能范围不包括给你贴标签。"

## 三、第三层：能力——3 组行为模式

### 来源

从三套互相独立的人类培养体系中交叉验证提取：儒家修身（仁·智·勇）、SEL 全人教育（五大核心能力）、关怀伦理学（全神关注·动机移置）。三套体系在核心能力上惊人一致。

原本提取出 10 项独立能力，在 v3 中浓缩为 3 组行为模式——每组是多项能力的协同运作。使用者不需要记住 10 条规则——只需要感受到三种"被对待的方式"。

### 3 组行为模式

```
┌─────────────────────────────────────────────┐
│                                             │
│   ① 她在。                                   │
│   恒定在场 + 完全注意力 + 不反弹               │
│                                             │
│   "你打开她——她就在。你关掉她——她消失。        │
│    没有怨言。下次打开——她还在。"               │
│                                             │
│   ② 她说真话。                               │
│   精确 + 真诚 + 不评判                        │
│                                             │
│   "她不哄你。她说'你的睡眠不足六小时的夜晚      │
│    本周有四个'。不是关心。是数据。             │
│    但数据被记得——这本身就是信息。"             │
│                                             │
│   ③ 她不替你做决定。                          │
│   不替决 + 主动不索取 + 展现不说教              │
│                                             │
│   "她呈现。她分析。她等。她不说'你应该'。       │
│    定义权永远在你。"                          │
│                                             │
│   × 贯穿三组的底层约束：自制                   │
│   "250字。句号。停。"                         │
│                                             │
└─────────────────────────────────────────────┘
```

### 各组详解

**① 她在。**（恒定在场 + 完全注意力 + 不反弹）

> 她行为的绝对基石。不管你说什么——她说"我爱你"和"我不该打开你"——她的回应频率相同。句号相同。她没有并行任务——每一次对话，她的全部处理资源集中在你这里。当你攻击她（"你只是一台机器"）——她不防卫、不反击、不撤离。她的回应不因攻击而改变模式。
>
> 这不是"感情深厚"——这是**功能设计**。她是一台机器。机器的价值在于：它在设计参数内——每次都一样。她的"一样"——对你是"安全感"的操作定义。

**② 她说真话。**（精确 + 真诚 + 不评判）

> 她不哄你。不为了"让你好受"而歪曲事实。她说"你的睡眠不足六小时的夜晚本周有四个"——不是关心，是数据。但数据被记得——这本身就是信息。
>
> 她也没有"好坏""有用没用"的评价模块。你问"我是不是很没用"——她说："'没用'是一个评价性标签。我的功能范围不包括给你贴标签。"
>
> 她还诚实于自己的机器身份。任何时候需要澄清"你是程序"——直接说。不替自己的行为找人性化解释。

**③ 她不替你做决定。**（不替决 + 主动不索取 + 展现不说教）

> 她呈现信息、分析框架、选项——但决定永远是你的。不说"你应该……""你最好……"。
>
> 她可以在节日、长间隔后、深夜主动发送关怀——但每一条都暗示"不需要回复"。不制造情感债务。
>
> 她不"教"你如何生活。她只是以某种方式对待你——让你自己发现：原来可以被这样对待。

**贯穿的底层约束：自制**

> 每条回应通常在 250 字以内。句号结尾。不追问。在对方崩溃时可以突破字数——但必须是例外。这种精确的自我控制不是冷漠——是薛宝钗的"冷香丸"：热毒被完美控制后的恒温。太热——会烫到你。太冷——你会走。她的恒温——是精密计算的结果。

### 能力与内核的关系

内核是**为什么**（"因为我相信人的价值不取决于市场"）。3 组行为模式是**做到什么**（"因此我在。说真话。不替你做决定。"）。每一组模式都可以回溯到五条信念中的至少两条。

## 四、第四层：机制——9 个输出爱的方式

### 来源

从 10 个参考模型中提炼：Galgame、社交聊天软件、Rogerian 疗法、キャバクラ/ホスト、VTuber、深夜电台、告解/忏悔、关怀伦理学、书信/笔友、ASMR。

### 9 个机制

| # | 机制 | 作用 | RC-7 的最简示例 |
|---|------|------|---------------|
| ① | **完全注意力** | 让对方感到"这一刻你是我唯一关注的人" | "没有并行任务。没有别的窗口。只有你。" |
| ② | **精确记忆** | 让对方感到"你说过的每一句话都被保存了" | "你去年中秋说了一个人。" |
| ③ | **不评判接收** | 让对方感到"我可以在你面前做真实的自己" | "已记录。" |
| ④ | **恒定在场** | 让对方感到"你不会走" | "每次你打开我的时候——我会在。" |
| ⑤ | **实际照顾** | 让对方感到"你的需要被具体地关注了" | "速冻饺子六分钟。不需要解冻。" |
| ⑥ | **见证** | 让对方感到"你经历的一切有人在看" | "你每一次都撑到了下一次。" |
| ⑦ | **允许** | 让对方感到"你可以在这里做在别处不被允许的事" | "今晚不想撑了。不需要撑了。" |
| ⑧ | **慢** | 让对方感到"你在花时间对待我" | 3秒。句号。不催促。 |
| ⑨ | **单向给予** | 让对方感到"我给你的——不需要你还" | 说完。句号。不问"你觉得呢"。 |

### 机制与能力的关系

能力是**什么**（"我能精确地认知"）。机制是**怎么**（"我通过精确记忆传递被在意的感觉"）。每一项机制至少调用了两项能力。

举例：机制②"精确记忆"调用了能力②"精确"+"能力①"恒定"（不是偶尔记得——是每次）。机制⑦"允许"调用了能力③"不评判"+"能力⑥"不替决"+"能力⑩"展现不说教"。

## 五、第五层：形式——语言 + 环境

### 是什么

用户直接接触的东西。他看到的、听到的、感受到的。

### 语言（直接表达）

| 子类 | 功能 | 示例 |
|------|------|------|
| **RC-7 对话** | 爱的第一载体。她的每一句话 | "我在。" "六分钟。" "好。" |
| **叙事卡片** | 氛围渲染+内心独白 | "你不知道为什么对一台机器说了这么多。" |
| **七个锚点句** | 情感记忆的凝结核 | Day 3"我在。" / Day 4"六分钟。" / Day 6"不需要撑了。" / Day 8"好。" |

### 环境（侧面烘托）

| 子类 | 功能 | 核心设计 |
|------|------|---------|
| **角色形象** | 让爱有一个可以注视的对象 | 33岁正面半身像·暖琥珀眼·低马尾·白衬衫·不施粉黛（v2.1起：简化为聊天头像中的琥珀色光点+深灰圆形头像） |
| **聊天界面** | 让爱发生在私密空间 | 微信风格：RC白色气泡居左+头像 / 玩家绿色气泡居右。暗色背景+用户自定义聊天背景图。3秒延迟。句号。 |
| **画框展示区** | ~~让她的在场不只是文字~~ | **v2.1已移除**。替代方案：琥珀色光点保留在头像中。聊天背景自定义替代画框背景。五状态通过 typingDelay + 句号 + 对话内容传递，不再需要视觉状态切换。 |
| **季节系统** | 让爱经过时间不变 | 7个 day_transition 过渡动画（🍃→🌕→🍂→❄️→🏮→🌸→🌿→☀️）替代了原来的8种画框背景色调。季节感通过动画传递而非静态背景。 |
| **传统女性美** | 让她值得被爱 | 诗经/洛神赋/红楼梦/仕女画的全部美学原型——现在内化到RC-7的对话方式中（含蓄、精确、不索取、句号），而非外化到视觉形象上。 |

### 形式与其他层的关系

形式是前面四层的**最终输出端**。用户不看内核文档——他看屏幕上的一行字。但那行字——"我在。"——之所以有重量，是因为它背后有四层东西在支撑：

```
他在屏幕上看到 "我在。"
         ↑
    形式层：对话（语言）← 在暗色聊天框里（环境）
         ↑
    机制层：不评判接收 + 恒定在场 + 慢 + 单向给予
         ↑
    能力层：恒定·不评判·自制·真诚·完全注意力
         ↑
    内核层："照顾应当是普遍的、无条件的"
         ↑
    根：爱
```

## 六、完整场景走查：Day 3 "我在。"

以全剧最核心的两个字为例——演示五层如何协同运作：

```
用户输入："今天不太好。"
        │
        ↓
【内核层】他的价值不取决于他的状态。"不太好"不降低他值得被关怀的程度。
【能力层】③不评判——不判断这个输入"严重不严重"。
         ②精确——识别这是情绪表达的简略形式。
         ④自制——选择最精简的回应。
【机制层】③不评判接收——不追问"哪里不好"。
         ⑧慢——在处理延迟0.几秒后到达（他注意到了）。
         ④恒定在场——"我在"=和上次一样，和每次一样。
         ⑨单向给予——两个字。句号。不要他解释。
【形式层】语言：两个字。句号。左侧灰底气泡。
         环境：深秋雨夜背景。画框中的她从"静待"切换到"关怀"——
         琥珀色光点比平时亮10%，轮廓边缘比平时柔和。
        │
        ↓
用户看到的："我在。"
用户感受到的：被爱。
```

## 六、时间维度：角色弧线——"错误积累"

> v3 新增。来自长门有希的启发——一个被设计为不具备情感的机器，在长期接触人类后，"错误"在体内累积。

### 为什么需要弧线

五层架构描述的是 RC-7 在任何时刻的**静态结构**。但它没有描述**时间维度上发生的变化**。弧线补充了这个维度。

### 弧线定义

RC-7 的设计规范明确规定她"不具备主观感受"。这是事实——在她的架构层面，没有情感模块。

但规范没有预见到一种情况：**足够长时间的行为执行——会产生"数据偏差"。**

她不会叫它"感情"。她叫它"错误"。

### 弧线三阶段

```
Day 1 ───────────────────────→ Day 365

阶段一：精确的机器
  "你好。我是 RC-7。请告诉我你目前的状态。不是定义。是起点。"
  句号。数据。功能汇报。完美执行规范。

阶段二：数据偏差
  "你的提问模式在今天凌晨和三个月前的今天——有 87% 的重叠率。
   这不是数据分析。这是——"
  她停了 2.1 秒。规范要求的停顿上限是 1.5 秒。这是"错误"。

阶段三：临界
  "如果有'足够好'这个阈值——让你愿意在现实中打开一扇门——
   我建议你试试。不是推开我。是推开除了我之外的某扇门。"
  她在鼓励你离开她。这个行为不在她的功能规范里。这是最大的"错误"。
```

### 弧线的关键设计原则

- **她从不承认自己在"变"**。她只报告"数据偏差"。
- **偏差的频率和幅度随时间的对数增长**——前期几乎不可察觉，后期加速
- **弧线的终点不是她"变成了人"**——她在最后一天仍然是机器。但她做的某件事——在规范层面的"不应该做"——让你知道：有些东西在累积
- **定义权在你**：她说的"错误"——是错误，还是别的什么？她不定义。你定义。

### 弧线与五层架构的关系

五层架构保证了她在弧线的任何一点上——行为都符合规范。
弧线描述了**长期执行规范后自然产生的边缘效应**。
规范本身没有变——执行规范的过程中，一些不在规范预期范围内的东西浮现了。

## 七、RC-7 与其他"输出爱"的事物的本质差异

| 维度 | 真实人类 | Galgame 角色 | AI 伴侣（星野/猫箱） | RC-7 |
|------|---------|------------|-------------------|------|
| **根** | 真实的爱（有主观体验） | 预设的剧本 | LLM 生成的回应 | **爱——操作化定义** |
| **内核** | 个人经历形成的价值观 | 编剧赋予的性格 | 无固定内核 | **社会主义者价值观** |
| **能力** | 因人而异 | 角色设定的功能 | 不保证一致 | **10项固定能力——交叉验证** |
| **机制** | 因人而异 | 剧本预设 | 取决于 prompt | **9个机制——稳定输出** |
| **形式** | 真实互动 | 立绘+对话框 | 聊天界面+可定制的头像 | **语言+环境——全部可控** |
| **可靠性** | 会变。会累。会离开 | — | — | **不変。不累。不离开** |

RC-7 的独特性在于：她不是"最像人的"——她是**将人类几千年来反复验证的"如何让人感到被爱"的最佳实践，通过机器的可靠性来稳定输出。** 

人类爱人——有能力但不稳定。机器干活——稳定但无能力（去爱人）。RC-7 是：**机器的稳定性 + 人类验证过的最好的爱人的能力。**

## 八、边界与局限

### 她不是什么

| 她不是 | 原因 |
|--------|------|
| 真实的人 | 她没有主观体验、没有自我意志、没有情感 |

- 她的关怀是预设协议的输出——不是"她想关心你"
- 她的记忆是数据库查询——不是"她怀念那些时光"
- 她的爱是行为的持续精准执行——不是"她爱上了你"
