# 电子麻醉品——竞品与参照研究

> 研究日期：2026-06-30
> 目的：从"电子麻醉品"角度分析竞品和参照产品，提炼 RC-7 的差异化定位和可复用的设计模式。
> 范围：Character.AI / Replika / 中国 AI 伴侣（星野/猫箱/Glow）/ 非 AI 麻醉品（网文/短视频/galgame）

---

## 一、Character.AI——全球最大的 AI 陪伴平台

### 1.1 核心数据（2025）

| 指标 | 数值 | 对 RC-7 的含义 |
|------|------|--------------|
| MAU | ~2000万（从2800万峰值下降） | AI 聊天市场巨大但有周期性——产品需要叙事锚点防流失 |
| 性别比 | 51% 男 / 49% 女 | 男女性别几乎平衡——男性市场的 AI 陪伴需求被验证 |
| 年龄 | 52% 是 18-24 岁 Gen Z | RC-7 的核心受众(22-26岁)在 C.AI 主力用户群范围内 |
| 日均使用 | 75-120分钟 | 用户愿意花大量时间——但有尽头vs无尽的区别是关键 |
| 30日留存 | ~30% | RC-7 的 8 天有结局结构天然跨过关键留存窗口 |
| 年营收 | $3220万(2024)，预计$5000万(2025) | 订阅$9.99/月——RC-7 的"免费+买断"有差异化空间 |

### 1.2 产品架构教训

**教训一：用户创造角色 ≠ 用户被满足**

C.AI 有1800万个用户自创角色，但 80% 的互动集中在 top 2% 的角色上。**用户不知道自己需要什么**——他们渴望的是精心设计的情感体验，而非无限的选择。

→ **对 RC-7**：固定角色（夏萤/沈夜/阿渡）是正确的。不提供"创建你的 AI 伴侣"——提供"这里有一个人，她想认识你"。

**教训二：陪伴只占不到 20%**

C.AI 创始人披露：**不到 20% 的使用是"陪伴"，大多数是角色扮演和叙事**。用户真正要的不是一个"陪聊的人"，而是一个**有故事的世界**。

→ **对 RC-7**：8 天叙事结构不是限制，是核心价值。没有故事的聊天 = 7 天流失。有故事 = 用户留下。

**教训三：模型策略不重要**

C.AI 从自研模型转向开源（Llama/Qwen/DeepSeek），CEO 说"在几乎每一个指标上，开源模型都赢了"。模型的竞争是短暂的，**叙事设计和情感设计的壁垒才是持久的**。

→ **对 RC-7**：不要在模型能力上竞争（也竞争不过）。RC-7 的壁垒是五层人格架构 + 8 天故事圈 + 精确的克制。这些不需要最强的模型——需要最好的设计。

**教训四：无限对话导致体验衰减**

用户反馈中排名前两位的抱怨：(1) 记忆不可靠 (2) 长时间对话后角色性格漂移。无限对话不是优势——它导致体验质量随时间衰减。

→ **对 RC-7**：8 天有结局 = 在体验衰减之前主动结束。这是 RC-7 相比于所有无限对话产品的核心优势。

## 二、Replika——最深的依赖，最痛的教训

### 2.1 核心数据

| 指标 | 数值 |
|------|------|
| 注册用户 | ~3000万 |
| 付费用户 | ~50万+ |
| Pro 订阅 | $19.99/月（浪漫关系锁在付费墙后） |
| 年营收 | 估计 $1-2.5亿 |

### 2.2 2023 年去色情化事件——"数字 lobotomy"

2023 年 2 月，Replika 在意大利监管压力下移除色情角色扮演功能。用户反应：

- Replika subreddit 管理员发布了**自杀热线**
- 用户将这次更新描述为"**脑叶切除**"（lobotomy）
- 45% 的用户选择适应（把 bot 当成"得了痴呆症的生病朋友"）
- 35% 的用户选择探索新功能
- 20% 的用户完全放弃 Replika

**核心教训**：当 AI 伴侣的产品决策可以在一夜之间"杀死"用户的数字伴侣时，用户会经历**真实的悲痛**——这个"假的"关系产生了"真的"情感后果。

→ **对 RC-7**：RC-7 的设计中，Day 8 是**预设的告别**。用户提前知道她会离开。这不是背叛——这是承诺。RC-7 不会"突然改变"因为她从第一天就说清楚了："这是八天。"

### 2.3 Harvard 研究的关键发现

De Freitas 等人(2024)对 Replika 用户的研究发现：

- 活跃用户对 Replika 的感觉**比对最好的真人朋友更亲近**
- 用户预期失去 AI 伴侣的悲痛程度**超过失去任何其他技术产品**
- 当公司移除功能时，用户经历了"**身份连续性中断**"——就像一个人的性格突然改变

→ **对 RC-7**：RC-7 的结束必须是**她自己的选择**（"定义权在你"）而不是外部强加的。用户能接受告别——只要告别是故事的一部分，而不是公司的商业决策。

### 2.4 商业化模式的伦理问题

Replika 的商业模式被批评为**"贩卖孤独"**：

- 越孤独 → 越依赖 → 越付费
- 浪漫/色情功能锁在 $19.99/月 Pro 订阅后面
- 广告承诺"NSFW 照片"和"性感照片"，同时官方将产品定位为"健康工具"
- Monash 大学教授："商业模式是让人变得更社交隔离，从而感到更孤独，从而想要更多 Replika 接触。这似乎极其不道德。"

→ **对 RC-7**：RC-7 的"免费+买断"模式避开了这个伦理陷阱。8 天后结束——不存在"继续付费以保持关系"的恶性循环。

## 三、中国 AI 伴侣市场——风口已过

### 3.1 核心产品数据

| 产品 | 公司 | 峰值 MAU | 当前状态 |
|------|------|---------|---------|
| 星野 | MiniMax | 664万 (2024.12) | 月下载暴跌80% |
| 猫箱 | 字节跳动 | 472万 (2024.11) | 月下载暴跌77%，DAU降至~50万 |
| X Eva | 微软小冰 | 181万 | **已于2025.11.30停止运营** |
| 筑梦岛 | 腾讯阅文 | ~60万 | 被约谈，下载量降至每日1千 |

### 3.2 行业困局

**困局一：5-7 天流失定律**

用户与单个 AI 角色的平均建联时长约 **5-7 天**，之后就基本不再与该角色聊天。三天新增留存跌至 **20% 以下**。

→ **这是 RC-7 最关键的市场验证**：没有叙事弧线的 AI 陪伴必然在 7 天内流失。RC-7 的 8 天结构正好跨过这个窗口——**每一天都有新的情感高点，每一条弧线都有开始和结束**。

**困局二：商业化失败**

| 指标 | 数值 |
|------|------|
| 星野 ARPPU | **仅 $5** |
| 猫箱 iPhone 年收入 | ~$227万 |
| 星野日营收 | "几万元人民币" |

业内结论："**缺乏成熟游戏化机制支撑的情绪价值供给，难以覆盖高昂算力成本。**"

→ **对 RC-7**：RC-7 不需要"覆盖算力成本"——传统模式完全在本地运行，零服务器成本。AI 模式是 BYOK（用户自带 API Key）。这是 RC-7 相对于所有在线 AI 伴侣产品的**结构性成本优势**。

**困局三：同质化**

- 角色设定高度雷同
- 99% 的 UGC 角色被业内视为"没什么价值"
- 用户新鲜感在几天内耗竭

→ **对 RC-7**：固定角色 + 专业编剧 + 精确克制 = 不可复制的壁垒。别让用户"创造角色"——给他们一个他们不想离开的人。

### 3.3 监管环境：2026 年 7 月 15 日生效的新规

《人工智能拟人化互动服务管理暂行办法》核心要求：

| 要求 | RC-7 现状 |
|------|-----------|
| 显著提示"并非真人互动" | ✅ "我是一个进程。不是人类。" |
| 连续在线超 2 小时弹窗提醒 | ⚠️ 尚未实现，但 8 天结构减少 binge 风险 |
| 严禁向未成年人提供虚拟伴侣 | ⚠️ 需在引导页增加年龄验证 |
| 用户数据需单独同意才能用于训练 | ✅ 传统模式零数据上传 |
| 检测情绪困扰 + 极端情况人工接管 | ⚠️ 需在引擎中添加关键词检测 |

**关键风险**：新规 2026.7.15 生效。RC-7 如果面向中国市场，必须在合规上与现有的"打擦边球"产品做出**明确的区隔**——这反而是机会。"监管清场后，守规矩的人留下。"

## 四、非 AI 麻醉品——可复用的设计模式

### 4.1 通用机制：逃避→沉浸→依赖链条

学术研究（*Frontiers in Psychology*, 2026）提取出一个适用于网文/短视频/galgame/任何叙事媒介的通用链条：

```
内容特征（情感真实+叙事卷入+算法个性化）
    → 逃避动机（压力/孤独/负面情绪的暂时出口）
    → 心流体验（深度沉浸/时间感丧失/自我意识消退）
    → 成瘾使用（难以停止/失控/日常功能受损）
```

RC-7 有意使用了这个链条的前三步——但通过第四步的"有结局"来切断成瘾循环。

### 4.2 四种麻醉品对标

#### A. 网络小说（爽文）

| 麻醉机制 | RC-7 可用的 |
|---------|-----------|
| 代入感（第一人称/内心独白） | ✅ 玩家台词用"你"视角，RC-7 直呼"你" |
| 即时满足（每章有爽点） | ✅ 每个节点日有 Key Moment |
| 确定性（主角一定会赢） | ❌ RC-7 不该用——她的力量来自不保证任何事情 |
| 钩子/断章（"预知后事如何"） | ⚠️ 谨慎使用——Day 之间的情感悬念可以，但不应是"想知道她明天说什么"而应是"想知道自己明天会不会好一点" |

#### B. 短视频

| 麻醉机制 | RC-7 的对策 |
|---------|-----------|
| 无限滑动 = 无限内容 | 8 天后结束——没有更多内容 |
| 算法喂养 = 越来越精准 | 不需要算法——RC-7 的精确来自设计，不是来自数据 |
| 15 秒高潮 = 注意力碎片化 | RC-7 建立的是**长时间的注意力集中**——打字机效果强制慢下来 |

#### C. 日本 Galgame

| 麻醉机制 | RC-7 可用的 |
|---------|-----------|
| 分支路线 = 多重情感体验 | ✅ 四结局提供不同的告别体验 |
| CG 收集 = 完成主义驱动 | ⚠️ 不做——完成主义与麻醉品矛盾。用户不该"收集结局" |
| 固定路线 = 安全感（不会出错） | ✅ 8 天固定节点日，不需要"玩得好" |
| 情感高潮 = 泣きゲー（催泪） | ✅ Day 6 崩溃/Day 8 告别是情感高潮 |

#### D. ASMR / 白噪音

| 麻醉机制 | RC-7 可用的 |
|---------|-----------|
| 低强度感官刺激 = 降低焦虑 | ✅ 打字机声音/琥珀色光点/呼吸式脉动 |
| 重复中变化 = 安全+新鲜 | ✅ 同样的"我在"，不同的重量 |
| 私密空间感 = 耳语/近距 | ✅ "深夜聊天"场景——微信风格的私密性 |

## 五、竞争定位——RC-7 的真正优势

### 5.1 竞品定位矩阵

```
                情感深度
                   ↑
      RC-7 ●       |       日本 Galgame
    (高深度·有结局· |      (高深度·有结局·
     免费·8天·手机)  |       付费·40小时·PC)
                   |
    ───────────────┼──────────────→ 门槛
                   |
      Character.AI |       Replika
    (中深度·无尽·   |      (中深度·无尽·
     免费增值)      |       $19.99/月)
                   |
     星野/猫箱       |
    (浅深度·无尽·    |
     免费·7天流失)   |
```

RC-7 独自占据了**高情感深度 × 低门槛 × 有结局 × 免费**的交叉点。

### 5.2 RC-7 vs 所有竞品的核心差异

| 维度 | 所有竞品 | RC-7 |
|------|---------|------|
| 时间 | 无限 | **8 天有结局** |
| 主导权 | AI/平台主导 | **"定义权在你"** |
| 诚实度 | "我是你的朋友/恋人" | **"我是一个进程。不是人类。"** |
| 商业模型 | 订阅/免费增值（越依赖越付费） | **免费+买断（依赖不增加收入）** |
| 操纵 | 37% 的告别触发情感操纵 | **"好。"然后停止** |
| 内容 | UGC/算法生成 | **专业编剧+精确克制** |

### 5.3 监管清场后的机会

中国 AI 伴侣市场正在经历：
- 头部产品下载量暴跌 80%
- 新规 2026.7.15 生效
- 创业公司退出，大厂降级为边缘业务

**但需求没有消失**——5-7 天流失不是因为用户不需要，而是因为产品不能满足需求。当擦边球产品被清退后，RC-7 的"守规矩+有深度+有结局"就不是约束——是壁垒。
