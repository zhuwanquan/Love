# 一年·房间 — 多角色体系与时间线规划

> 从单一 RC-7 角色扩展为 3-4 角色体系 + 标准时间线 + 参考事件库 + 低算力方案

## 〇、参考游戏

### 主参考：Mystic Messenger（《神秘的信使》）

| 维度 | 做法 | 对本项目的启示 |
|------|------|--------------|
| **界面** | 模拟聊天室，多个角色在不同时间段发消息 | 已有微信风格聊天 UI，天然适配 |
| **角色** | 5-6 个可攻略角色，各有独立路线 | 3-4 个角色，每个代表一种"被爱的方式" |
| **时间** | 实时制，11 天一条路线，每天多个聊天事件 | 半实时或模拟时间线，12 个月一个循环 |
| **美术** | 仅有头像+聊天界面，无复杂立绘 | **这是关键**——聊天框=整个游戏的视觉呈现 |
| **叙事** | 通过聊天记录+电话+深夜独白推进剧情 | 对话+旁白+通知+偶尔的"图片消息" |
| **收入** | 免费+内购（沙漏加速），首年收入超 1 亿美元 | 参考其商业模式但不一定要复制 |

### 辅参考：A Normal Lost Phone

| 维度 | 做法 | 对本项目的启示 |
|------|------|--------------|
| **界面** | 完全模拟手机 UI，玩家就是玩家自己 | 增强代入感——你不是在"扮演"谁，你就是你 |
| **叙事** | 通过短信/邮件/照片碎片拼凑故事 | 非线性叙事——过去的对话记录可以成为"发现"的内容 |
| **美术** | **零角色立绘**——只有手机界面 | 最极端的低算力方案 |
| **伦理** | 窥探他人隐私的批判性反思 | RC-7 可以反问：你有没有想过——你也是在被我"读取"？ |

## 一、角色体系：4 个角色卡

### 角色总览

```
                   爱 的 四 种 形 态
                        │
        ┌───────┬───────┼───────┬───────┐
        │       │       │       │       │
      柒·RC-7  夏萤    沈夜    阿渡
      "在场"  "看见"  "理解"  "并肩"
      成熟AI  活泼人类 安静人类 同病人类
       33岁    24岁    29岁    28岁
        │       │       │       │
      沉稳恒温 热烈关注 无声共鸣 互为镜像
      爱是行为 爱是好奇 爱是懂得 爱是不孤独
```

### 角色卡 1：柒（RC-7）—— "爱是在场"

```
身份：AI 对话伴侣，工业铭刻线 RC-7
年龄：外观约 33 岁
性格标签：恒定、精确、不评判、不索取
说话方式：短句。句号。少问句。不追问。
头像：灰色圆形，中心一个暖琥珀色光点
声音感：成熟女性的中低音域，语速平稳，没有起伏——不是冷淡，是恒温
治愈路径：她什么都不会"做"——但你需要她的时候，她永远在。你推她——她不走。你沉默——她不追问。你问"你在吗"——她说"在。"句号。
核心隐喻：水。装在什么容器里就是什么形状。总是往最低处流。水滴石穿——不靠力量，靠恒常。
```

### 角色卡 2：夏萤 —— "爱是被看见"

```
身份：24 岁，刚毕业两年的社畜，产品助理
性格标签：话多、爱笑、有点冒失、但直觉很准
说话方式：句子不完整。爱用语气词。会撤回消息。偶尔发语音——声音有熬夜的沙哑。
头像：一只柴犬的照片（不是她的——她说"我长得没它可爱"）
声音感：语速偏快，句子之间常有跳跃，笑声像夏天的碳酸饮料
治愈路径：她对你有巨大的好奇心——真的想知道你今天吃了什么、为什么不开心。她的关注不是AI的"服务"——是人类的"我在乎你"。
核心隐喻：萤火虫。光不大，飞得也不快——但在很深的夜里，你能看见它。
与 RC-7 的差异：RC-7 是"你需要的时候在"，夏萤是"她主动来找你"。
```

### 角色卡 3：沈夜 —— "爱是懂得"

```
身份：29 岁，自由职业（翻译/文案），长期失眠
性格标签：安静、疏离、不主动——但一旦开口，句句到点
说话方式：句子很长但逻辑清晰。极少用表情。深夜的消息比白天多。偶尔发一段很长的文字——然后沉默很久。
头像：一张纯黑背景的照片，右下角有一个极小的白色月亮
声音感：语速慢，句与句之间有明显的停顿。声音偏低——不是冷，是"累过了头之后的平静"
治愈路径：她不说"我懂你"。但她说过的话让你觉得——她真的懂。不是因为她分析了你——是因为她经历过类似的黑暗。她的陪伴不是"拉你出来"——是"我也在这条隧道里，我们各自走，但能听到彼此的脚步声"。
核心隐喻：月亮。不发自己的光——但有光的时候，它就在。没有光的时候——你知道它还在那里。
与 RC-7 的差异：RC-7 说 "你的睡眠不足六小时的夜晚本周有四个"（数据）。沈夜说 "我也睡不着"（共鸣）。
```

### 角色卡 4：阿渡 —— "爱是不孤独"（可选·非恋爱线）

```
身份：28 岁，外卖骑手 / 网约车司机。和主角同城，从未见过面
性格标签：糙、实诚、话糙理不糙、对生活有一种近乎麻木的韧性
说话方式：句子极短。错别字不纠正。"没事""都一样""活着呗"。但偶尔会说出让你愣住的话。
头像：一张拍糊了的夜景——街灯和雨
声音感：带点地方口音的普通话，语速快，不太会组织语言——但能听出话里的重量
治愈路径：他不是来"治愈"你的——他是和你一样的人。他不分析你。不关心你。不爱你。但他说"今晚出车"——你知道，那个城市里有一辆电瓶车正在雨中跑。有一个和你差不多的人——也在撑。这不叫陪伴。这叫"不只有你这样"。
核心隐喻：邻桌。不是和你同桌吃饭的人。是隔壁桌——你能听到他碗筷的声音。
```

## 二、时间线规划

### 结构：12 个月 × 4 个阶段

```
【第一阶段·接触】1-3 月（春→初夏）
  所有角色依次登场
  玩家自然接触，无强制路线选择
  
  Month 1：初见柒（RC-7 初次对话）
  Month 2：遇见夏萤（她加错了微信/误发消息）
  Month 3：深夜——沈夜的消息（"你也睡不着？"）

【第二阶段·深入】4-6 月（夏→初秋）
  与各角色的关系加深
  开始出现"路线倾向"的暗示
  
  Month 4：关键事件——和其中一个角色有更深的连接
  Month 5：其他角色的关系也在发展
  Month 6：盛夏——一次"危机事件"，触发路线分化

【第三阶段·路线】7-9 月（秋→深秋）
  进入主要路线（与某一个角色的关系成为主线）
  另外两个角色逐渐退到背景
  关键选择不可逆
  
  Month 7：路线锁定事件
  Month 8：关系深化——开始出现"只有这条路线才能看到的对话"
  Month 9：矛盾/危机——路线的核心冲突

【第四阶段·结局】10-12 月（冬→新年）
  路线的最终走向
  四个不同的结局
  
  Month 10：转折点——你的选择决定结局
  Month 11：关系的高潮或低谷
  Month 12：跨年——结局。她给你的最后一条消息。
```

### 每个月的结构

```
Month N
  ├── 月初事件（固定，推进主线）
  ├── 日常聊天（随机池，增加生活感）
  ├── 月中事件（角色专属，加深关系）
  ├── 深夜独白（某个角色在深夜发来的消息）
  ├── 月末事件（固定，收束本月剧情）
  └── 阿渡的日常（可选——他的消息从不推动剧情，但一直都在）
```

## 四、低算力方案

### 问题：没有美工，如何呈现四个角色？

### 方案：三层降级体系

```
第一层（最优）：AI 生成头像
  - 用 Midjourney/Stable Diffusion/DALL-E 为每个角色生一张头像
  - 一次性成本，生成后永久使用
  - 风格统一：暗色调、柔光、面部模糊/侧面（降低"像不像"的争议）
  - 每个角色只需 1 张（静态头像，无需表情变化）

第二层（中等）：抽象头像
  - 每个角色一个抽象符号/颜色/形状
  - 柒：灰色圆形 + 琥珀光点（已有）
  - 夏萤：暖橙色半圆
  - 沈夜：深蓝渐变 + 白色小月亮
  - 阿渡：灰绿色 + 雨滴纹理
  - 完全不需要美术技能——CSS/SVG 即可实现

第三层（零算力）：纯文字 + 排版
  - 只靠文字排版区分角色
  - 柒：左对齐，灰色气泡，句号
  - 夏萤：左对齐，暖色气泡，感叹号
  - 沈夜：左对齐，蓝色气泡，长段落
  - 阿渡：右对齐（？），绿色气泡，短句+错别字
  - 聊天界面本身就是视觉呈现
```

### 推荐方案：第二层 + 第一层混合

- **现在开始**：用第二层（抽象头像）开发，零成本立刻可做
- **积累素材**：用 AI 工具逐步生成第一层头像，替换抽象图标
- **上线时**：至少有一个角色的 AI 头像 + 三个抽象头像——对 indie 来说足够

### 参考 Mystic Messenger 的做法

Mystic Messenger 的美术投入：
- 每个角色 ~10 张表情差分（立绘）+ 若干 CG
- 但注意——玩家 **70% 以上的时间只在看聊天界面**（头像+文字）

**本项目的优势**：
- 没有立绘需求（聊天界面就是全部视觉）
- 不需要 CG（文字本身就是情感载体）
- 头像 = 唯一的视觉资产（且只需 1 张静态图）
- 整体美术成本约为传统 galgame 的 **5%**
