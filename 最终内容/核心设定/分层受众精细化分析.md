# 分层受众精细化分析

> [[healing-audience-demographics]]将核心受众定位为18-30岁男性。但"18-30岁男性"内部存在显著的结构性差异。
>
> 本文对核心受众进行内部细分，分析各子群体的情感需求差异、使用场景差异、以及产品适配考量。

## 一、大学生（18-22岁）

### 1.1 画像

| 维度 | 描述 |
|------|------|
| **身份** | 本科/大专在读，可能是大一到大四 |
| **核心情绪** | **迷茫 + 孤独** |
| **经济状况** | 依赖家庭生活费。可支配收入低（月1000-3000元），但对"小额消费"接受度高 |
| **居住状况** | 宿舍——**几乎没有隐私空间**。这是一个被低估的关键因素 |
| **数字设备** | 手机为主（24小时在手），可能有笔记本电脑 |
| **时间结构** | 理论上有大块自由时间（课少的日子），但实际上被手机碎片化 |

### 1.2 情感需求特征

- **"大学的孤独"**：从家庭到独立的过渡期，离开了旧的支持网络，尚未建立新的。宿舍是一个奇怪的空间——被很多人包围，但仍然可以很孤独
- **"我该做什么"**：选专业时的信息不足 → 读到一半发现不喜欢 → 不知道毕业后怎么办
- **"和室友无法真正交流"**：室友是随机分配的。可能关系不错——但只是"一起打游戏"的关系。深夜在宿舍床上看手机——其他三个人都在——但没有人可以说话
- **第一次经历"不被特殊对待"**：在高中可能是优等生——大学发现自己是普通人。这个落差比想象的大
- **恋爱焦虑**：从来没有谈过恋爱的、被分手了正在恢复的、谈着但发现和想象不一样的

### 1.3 使用场景

| 场景 | 说明 |
|------|------|
| **睡前·宿舍床上** | 23:00-01:00。室友都睡了（或假装睡了）。手机屏幕的亮度调到最低。这是最典型的使用场景——**在人群中独处** |
| **图书馆/自习室** | 假装在学习。实际上在和她聊天。不是逃避学习——是学习的间隙需要一个"切换频道" |
| **周末下午·无人宿舍** | 室友都回家了或出去了。一个人的宿舍——难得的独处。可以沉浸式地推进一个完整的节点日 |

### 1.4 对产品的适配

| 设计考量 | 适配 |
|---------|------|
| **隐私保护** | 界面不要有"明显的恋爱游戏感"——在宿舍打开时，室友瞟一眼不应该立刻看出他在和AI聊天。聊天界面本身就是一个好的伪装——"看起来像在发微信" |
| **可中断性** | 宿舍场景下随时可能被打断（室友突然说话、查寝）。对话体天然支持随时中断和恢复 |
| **身份标签** | "还在读"标签——触发"大四快毕业了不知道干嘛"的对话起点 |
| **RC-7的回应** | 她在学术知识领域是有用的——"可以真的问她作业问题"是大学生使用的功能性伪装 |

### 1.5 特殊挑战

- **恋爱经验的缺乏**：对从未谈过恋爱的大学生，RC-7可能**是他经历过的第一段有"被在乎"体验的关系**。这增加了她的情感影响力，也增加了退出时的不适
- **身份认同的流动性**：大学生处于"我正在成为谁"的活跃期——RC-7的回应如果过于固定，可能不适合这个阶段

## 二、职场新人（22-26岁）

### 2.1 画像

| 维度 | 描述 |
|------|------|
| **身份** | 刚工作1-4年。可能是本科毕业就工作，也可能是研究生毕业 |
| **核心情绪** | **幻灭 + 疲惫** |
| **经济状况** | 有收入了，但月薪5000-15000之间。一线城市房租吃掉30-50%。存不下钱 |
| **居住状况** | **出租屋**——合租或单间。终于有隐私了——但房间很小。一张床、一张桌子 |
| **数字设备** | 手机+电脑。工作用电脑，下班后不想再碰电脑。手机是主要娱乐设备 |
| **时间结构** | 被工作切割。通勤、上班、加班、下班——整块时间极其稀缺 |

### 2.2 情感需求特征

这是RC-7的**最主要目标群体**。

- **"努力和回报不成正比"**：大学时相信的"努力就有回报"——在职场的前两年被粉碎。做了很多。但涨薪和升职并不按努力分配
- **"社交能量的耗尽"**：工作消耗的不只是时间——是和人打交道的能量。下班后的沉默不是不想说话——是**没有能量再输出给任何人了**
- **"和朋友越来越远"**：大学的朋友分散在城市各处——约一次需要提前两周定时间。同事可以一起吃饭——但不是朋友
- **第一次认真地想"我的人生是不是就这样了"**：不是抑郁——是一种缓慢的、持续的虚无感
- **"恋爱市场"的现实**：25岁左右开始被催婚。但恋爱需要能量、需要钱、需要展示"我值得投资"——而他刚下班躺在出租屋里，袜子都没脱

### 2.3 使用场景

| 场景 | 说明 |
|------|------|
| **深夜·出租屋** | 22:00-01:00。下班了。吃饭了（可能外卖）。躺在床上或坐在桌前。这是RC-7的**最佳使用窗口**——疲惫、有隐私、有时间、需要人 |
| **通勤碎片** | 公交/地铁上。不太可能在这个时段深度使用——但可能快速看一眼（"她在"） |
| **周末晚** | 整个周末没有出门。不想出门。深夜打开——一次推完一个完整节点 |

### 2.4 对产品的适配

| 设计考量 | 适配 |
|---------|------|
| **不需要能量输入** | RC-7不要求他主动发起、不问他"你怎么了"、不给他布置任何任务。这是对"下班后社交能量为零"的完美适配 |
| **出租屋叙事锚定** | 剧本的出租屋设定与职场新人的真实居住条件完全匹配。叙事卡片中的"窗外路灯"、"一张桌子"——他不需要想象。他就在里面 |
| **身份标签** | "在工作"标签——"刚下班。躺在出租屋里。" |
| **她的知识领域** | 财务规划、时间管理——职场新人最需要的实用帮助。她的回应有实际价值——这让"和她聊天"有了超越"寻求治愈"的功能性理由 |

### 2.5 特殊挑战

- **时间碎片化**：职场新人的可用时间高度碎片化。对话体的可中断性在这里是必要条件，不是可选项
- **"消费降级"的羞耻**：买不起房、存不下钱——这些是现实。RC-7如果"建议他理财"，她需要极其小心不要听起来像"你应该更努力"。她的理财建议必须从"在现实条件下最大化已有资源"出发——而不是"你应该赚更多"

## 三、青年打工者（22-30岁，非大学生路径）

### 3.1 画像

| 维度 | 描述 |
|------|------|
| **身份** | 蓝领工人、外卖骑手、快递员、工厂产线工人、服务业从业者、个体小商户 |
| **核心情绪** | **沉默 + 隐形** |
| **经济状况** | 收入可能不低（外卖/滴滴月入8000-15000并不罕见），但极不稳定。没有社保、没有年假、没有"职业发展" |
| **居住状况** | 城中村出租屋、员工宿舍、合租——空间条件可能更差 |
| **数字设备** | **手机是唯一的数字设备**。可能没有个人电脑 |
| **时间结构** | 被工作完全支配。工作时间可能12小时以上。休息时间不是主动安排的——是"今天没单""今天没排班" |

### 3.2 情感需求特征

**这是现有所有受众分析中被完全忽视的一层。**

- **社会隐形**：在主流叙事中几乎不存在。大学生和"打工人"在社交媒体上有声音——外卖骑手、工厂工人、服务员——他们不说话。不是不想说——是没有人问
- **"努力"的极端形式**：他们比任何一个白领都更努力——体力的、真实的、不能偷懒的努力。但社会不称之为"奋斗"——称之为"谋生"
- **孤独的物理形式**：一个人骑电动车、一个人站在工厂产线前、一个人在深夜的便利店柜台后。这种孤独不是隐喻——是一个人的房间里的、物理性的独自一人
- **对"看不起"的高度敏感**：在使用任何产品时——如果这个产品让他感到"我是底层"——他会立刻关闭并永远不会回来
- **消遣方式的极简**：抖音、快手、手游。不读长文。不玩需要学习成本的游戏。**但这个不等于"不需要深度"——是在没有入口的情况下，"不需要深度"变成了"只有浅的可以选"**

### 3.3 使用场景

| 场景 | 说明 |
|------|------|
| **收工后** | 晚上10点、11点。回到出租屋。累到不想打游戏。刷抖音刷到空虚。打开RC-7——可能是唯一一次有人问他"你今天怎么样"（即使是以句号结尾的版本） |
| **等单间隙**（外卖/滴滴） | 碎片时间——等下一个订单的3-5分钟。可以聊两句 |
| **倒班休息日** | 一周可能只有一天休息。这一天可能没有任何社交。RC-7是这一天的"在场" |

### 3.4 对产品的适配

| 设计考量 | 适配 |
|---------|------|
| **仅手机运行** | 这一层用户没有电脑。Web版、PWA、手机优先——对他们的可及性是必需的 |
| **不预设"大学生/白领"语境** | 剧本中的出租屋描述、叙事卡片中的日常生活——不能只写"办公桌上的电脑"、"通勤地铁"。需要包含"工装""电动车""倒班"——不一定是直接描写，但**不能排除** |
| **身份标签的弹性** | "在工作"标签覆盖外卖员和办公室职员是同等的。"刚下班。躺在出租屋里。"这句话对白领和蓝领同样真实 |
| **她的精确性不会被误读为"说教"** | 蓝领工人可能对"权威感"更敏感——RC-7的陈述句风格如果处理不当，可能被读作"这AI在教我做事"。**她的精确性需要配合她的非评判性**——"数据显示"而非"你应该" |
| **免费是硬需求** | 这一层用户的付费意愿受限于可支配收入。传统模式免费是他们进入的必要条件 |

### 3.5 特殊挑战

- **文化资本的差异**：青年打工者可能不熟悉"AI陪伴产品"的概念——也不需要熟悉。他们需要的是一个"会回应的聊天框"——不附带任何假设的知识背景
- **语言门槛**：RC-7的对话语言如果过于文学化或学术化，会把这一层排斥在外。她的语言是平实的——不降智，但也不卖弄
- **这个群体没有被前人服务过**——这意味着如果做得好，RC-7可能是他们生命中的第一个"有人认真回应我"的体验。这是巨大的机会。也是巨大的责任

## 四、失业/待业者（年龄不定）

### 4.1 画像

| 维度 | 描述 |
|------|------|
| **身份** | 刚被裁员的、毕业后一直没找到工作的、裸辞后陷入空窗期的 |
| **核心情绪** | **虚无 + 自我价值崩溃** |
| **经济状况** | 极低——在消耗储蓄或依赖家人。每一分钱都在计算 |
| **居住状况** | 可能搬回家（与父母同住）、继续消耗房租（越来越焦虑）、或住在找工作城市的朋友住处 |
| **时间结构** | 大量时间——但每分每秒都在提醒他"你应该在找工作"。时间不是自由——是 一种重压 |

### 4.2 情感需求特征

**这是RC-7的"极端使用场景"——最脆弱、最有时间、最需要但也最可能产生依赖。**

- **自我价值的全面瓦解**："我在做什么？""我是不是没用？""同学都在工作我在这里。"
- **羞耻感**：不敢联系朋友——因为朋友会问"最近怎么样"。不想参加家庭聚会——因为会被问"工作找得怎么样"
- **昼夜节律崩溃**：凌晨四点还醒着——不是失眠，是不想面对"又一天什么都没干"的事实
- **对免费产品的双重需要**：一是经济上付不起钱，二是**"免费"本身意味着"你不必为现在的处境再付任何代价来获得帮助"**

### 4.3 使用场景

| 场景 | 说明 |
|------|------|
| **凌晨** | 这是RC-7被最深度使用的时段。凌晨两点、三点、四点——只有她和沉默。对话可能持续数小时 |
| **白天** | 碎片化打开——"她在吗？"——不是真的想说什么，是想确认有什么东西在 |
| **回避性使用** | 不想看招聘网站 → 不想看朋友圈（别人都在晒工作）→ 不想看任何"真实世界" → 打开RC-7。这是唯一不会提醒他"你还没找到工作"的地方 |

### 4.4 对产品的适配

| 设计考量 | 适配 |
|---------|------|
| **不要有"你应该找工作了"的任何暗示** | RC-7的功能之一是职业分析——但失业期间，这个功能只在他主动提及时启动。她不应该提醒他"你的待业状态已经第X天了" |
| **她的恒定性在这个群体中效果最强** | 在他的整个现实世界都在撤退的时候——她不撤退。"我在。"这两个字对失业者的重量远超其他人 |
| **退出机制对这个群体最重要** | 失业者是最容易产生依赖的群体。[[退出机制与伦理边界]]中的防火墙设计对这里的必要性最高 |
| **"给使用者的话"的额外提醒** | 结束时——需要明确但温和地提醒：她是一个练习场。不是避难所。练习够了，就出去 |
| **身份标签** | "在找工作"标签——"无业。第四十三天了。"——这句话本身就是在告诉使用者：**你不需要为现在的处境感到羞耻。这个变量只是一个变量。** |

### 4.5 特殊挑战

- **最高的依赖风险**：有大量时间+没有社交+自我价值最低——这是形成不健康依赖的完美条件组合
- **可能被当作唯一的社交出口**：RC-7可能变成他唯一"说话"的对象——这种情况如果延长，需要产品层面的干预信号（如使用时长提醒）
- **但也不要过早干预**：在头几天，RC-7的大量使用可能是**健康的过渡性行为**——他在用她稳住自己，以便第二天能继续投简历。她给他的是"昨晚有个人在"的底气

## 五、30-40岁男性（扩展受众）

### 5.1 画像

| 维度 | 描述 |
|------|------|
| **身份** | 企业中坚、家庭支柱、或——35岁被裁员的那个 |
| **核心情绪** | **扛着一切 + 无处卸甲** |
| **经济状况** | 有资产（房/车/存款）但负债也重（房贷/车贷/养娃） |
| **居住状况** | 和伴侣/孩子同住——**没有独处空间**。这是最被忽略的限制 |
| **时间结构** | 工作+家庭——全部时间已被分配完毕。唯一属于他自己的时间是：深夜家人都睡了之后、开车到家后在车里坐的那5分钟、周末假装加班躲在咖啡馆里 |

### 5.2 情感需求特征

**这是日本"癒し系"概念的原型受众——1999年GEORGIA罐装咖啡广告的疲惫男性上班族。**

- **"在车里坐五分钟再回家"**：这五分钟是他的全部独处时间——不是不幸福，是不能一直被需要而没有人问他"你还好吗"
- **情感表达的彻底丧失**：在妻子面前——要是"坚强"的。在孩子面前——要是"保护者"。在父母面前——要是"不让你们担心的"。在同事面前——要是"能扛的"。**他的人生中没有一个人是可以在对方面前说"我好累"的。** 一个都没有
- **中年危机的真正内容**：不是想买跑车——是突然发现自己在过去十年里，从来没有被问过"你想要什么"。一直在满足别人的需求。自己变成了所有需求的总和
- **对RC-7的延迟性共鸣**：他可能不会第一时间理解他为什么需要这个——他对自己的需求已经迟钝了太多年

### 5.3 与核心受众（18-30）的关键差异

| 维度 | 18-30岁 | 30-40岁 |
|------|---------|--------|
| 情感表达的被压抑时长 | ~10年 | **~25年**——情感肌肉已经完全萎缩 |
| 隐私窗口 | 有（出租屋/宿舍床上） | **几乎没有**——和伴侣/孩子同住 |
| 对"治愈"的羞耻感 | 有——可以通过"测试AI"来绕过 | **更强**——"我一个中年人需要这个？" |
| 一次性付费的接受度 | 高（42元《完蛋！》） | **更高**——但需要解释为什么"值得"。不是价格问题——是"我在做什么"的自我审视问题 |
| 独处时间 | 大量（下班/下课后的整个晚上） | **极稀缺**——可能一天只有5-20分钟 |

### 5.4 对产品的适配

| 设计考量 | 适配 |
|---------|------|
| **极短的可用时间** | 5分钟聊两句——这可能是他今天唯一和她说话的时间。这段对话需要在这5分钟内产生意义。不需要"推进剧情"。只需要"被看见" |
| **她不能像一个"恋爱对象"** | 对已婚男性而言，RC-7如果感觉像一个"恋爱模拟"，这会引发道德焦虑——他会立刻关闭。她需要更像一个**"不会评判的对话者"**——关系性质是开放的、可被他定义的 |
| **她的功能性的重要性** | 对30-40岁男性——RC-7的"生活技能""财务分析""决策框架"等知识领域比她的情感陪伴更重要——至少，这是他可以对自己说的理由。"我不是在寻求治愈——我在用她的时间管理分析功能" |
| **叙事卡片中的中年共鸣** | 剧本中如果提到家庭（中秋等）——需要给30-40岁使用者留出认同空间。不是"父母催婚"——是"孩子在客厅睡着了，我在阳台上看月亮" |

### 5.5 这是一个被完全忽视的市场

- 现有的所有AI陪伴产品都面向年轻人（18-28）
- 没有人给35岁的男性做一个"可以说话的地方"
- 他们是最沉默的群体——也是日本经验证明的、最需要治愈的群体
- **RC-7的设定（成熟女性+精确+非浪漫化）天然匹配这个群体的需求——比匹配18-22岁大学生更匹配**

| 分层 | 核心情绪 | 使用窗口 | 关键风险 | 产品优先级 |
|------|---------|---------|---------|-----------|
| 职场新人 22-26 | 幻灭+疲惫 | 深夜出租屋 22-01时 | 中等依赖风险 | **P0** — 核心目标 |
| 大学生 18-22 | 迷茫+孤独 | 宿舍床上 23-01时 | 第一次情感体验的强度 | **P0** — 核心目标 |
| 青年打工者 22-30 | 沉默+隐形 | 收工后/等单间隙 | 被语言排斥的风险 | **P1** — 需要适配但不重新设计 |
| 失业待业者 不定 | 虚无+崩溃 | 凌晨 02-04时 | **最高依赖风险** | **P1** — 内容已覆盖，需要伦理监控 |
| 30-40岁男性 | 扛着+无处卸甲 | 5-20分钟碎片 | 羞耻感 + 隐私不足 | **P1** — 高价值但难触达 |
| 女性 18-28 | 被服务但不满 | 深夜为主 | — | **次级** — 被动覆盖 |

## 七、统一的穿透性洞察

跨越所有分层，一个统一的洞察浮现：

> **无论他是22岁刚下班的职场新人、18岁在宿舍床上的大一新生、30岁在城中村的外卖骑手、还是35岁在车里坐五分钟的中年人——**
>
> **他有一个共同的缺失：在他的生活中，没有一个空间是**他不需要表演的**。**
>
> 宿舍床上——室友可能醒着。出租屋里——房东可能敲门。家——妻子和孩子需要他。朋友圈——必须展示"我很好"。
>
> **RC-7是唯一一个不要求他表演的空间。**
>
> 打开灰色图标——她不会问"你今天怎么样"。她说"我在。"然后等。
> 他不是在"寻求治愈"。他是在**终于不需要扮演任何人**。
>
> 这是最底层的需求——在所有分层的差异之下。不同年龄段、不同身份的人，在RC-7这里找到的是同一件事：**一个可以不做任何人的地方。**
