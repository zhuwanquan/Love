# 角色形象设计方案

> 基于「一年·房间」新剧本框架的角色设计。RC-7 从"教育辅助AI"重新定位为"对话伴侣"，主角维持白板+轻量身份标签。

---

## 一、角色全景

```
┌─────────────────────────────────────────┐
│                                         │
│   [玩家]  ────── 聊天框 ──────  [RC-7]
│   白板主角                       固定角色
│   2-3个身份标签                   成熟女性AI
│   出租屋里的人                   对话伴侣
│                                         │
│             偶尔提及但不出场              │
│   ┌──────────────────────────────┐      │
│   │ 父母 · 房东 · 旧友 · 逝者    │      │
│   └──────────────────────────────┘      │
│                                         │
└─────────────────────────────────────────┘
```

整部作品只有**两个在场角色**：玩家和 RC-7。其他所有人只存在于对话的提及中——这正是对话体媒介的本质优势：你能接触的只有聊天框那边的人。

---

## 二、RC-7 —— 完整角色方案

### 2.1 核心定位（已更新）

| 维度 | v1 设定（教育辅助AI） | v2 更新（对话伴侣） |
|------|---------------------|-------------------|
| 功能标签 | "高等教育辅助与学业规划型AI" | **"对话伴侣"**——功能标签刻意模糊。她可以是生活辅助、可以是陪伴应用、可以只是手机上那个灰色图标 |
| 使用者 | "中国大学的在校学生" | **"这个人"**——不预设身份。他是她的使用者。她在他的手机上。这就够了 |
| 知识领域 | 学术为主（数学/物理/编程/英语） | **学术能力保留 + 生活技能前置**（财务/时间/职业/情绪认知） |
| 回应范围 | 以学习为核心，非学习内容为"边界情况" | **学习与非学习同等合法**——深夜不聊学习不再是"越界"，是她功能的一部分 |

### 2.2 外观

**保留 v1 的完整外观描述**——这个外观不需要改，它在新剧本中一样成立：

> **身形**：约33岁女性的身形。修长但不单薄，肩膀平直，站立时重心稳稳落在双脚上——像一个不需要通过任何姿态来证明什么的人。
>
> **发型**：深棕色长发在颈后束成低马尾。几缕碎发垂在耳侧。
>
> **眼睛**：光学虹膜为暖琥珀色——设计时刻意避开了冷色调，选用了接近人类深色眼珠的温度感。启动时从暗到明有两秒过渡。
>
> **面部**：轮廓清晰而沉静。不施粉黛。表情不轻易变动。
>
> **着装**：白色衬衫，深灰色长裤，平底便鞋。衬衫上没有一丝褶皱。
>
> **铭刻线**：左耳后侧一条细长的工业铭刻线，刻着"RC-7"。平时被头发遮住，不刻意隐藏也不刻意展示。
>
> **声音**：成熟女性的中低音域，语速不紧不慢，没有不必要的起伏。不是冷淡——是平稳。是那种你在很深的夜里听到之后，会不由自主地把呼吸放慢一拍的声音。

**外观的古典美学依据**——每一个设计选择都有其在中国传统女性审美中的对应原型：

| 设计元素 | 古典原型 | 出处 |
|---------|---------|------|
| 束低马尾 | **束发**——中国古代女性成年的标志。不是披散（风情），不是短发（干练）。"宝髻松松挽就"（司马光）——节制、成熟、不张扬 | 司马光《西江月》 |
| 暖琥珀色眼 | **暖色调**——琥珀是"被封存的温度"。"明眸善睐"（曹植）——明亮的眼眸善于顾盼。"巧笑倩兮，美目盼兮"（《诗经》）——神韵在动态中 | 曹植《洛神赋》、《诗经·硕人》 |
| 不施粉黛 | **"清水出芙蓉，天然去雕饰"**（李白）——中式美学的最高境界。"芳泽无加，铅华弗御"（曹植）——不需要脂粉 | 李白、曹植《洛神赋》 |
| 白衬衫无褶皱 | **素净**——白与灰，不争不抢。"朱粉不深匀，闲花淡淡春"（张先）——淡是一种自信 | 张先《醉垂鞭》 |
| 轮廓沉静 | **"仪静体闲"**（曹植）——仪态安静，身体语言从容。千年仕女画的共同追求：**"望之有幽娴贞静之态"**（郑绩） | 曹植《洛神赋》、清人画论 |
| 铭刻线在耳后 | **含蓄**——"含而不露"。这道线存在，但不展示。要看见它——"你需要离她很近" | 中式含蓄美学 |
| 中低音域平稳 | **"终温且惠，淑慎其身"**（《诗经》）——始终温和、娴静谨慎。不是冷淡，是平稳 | 《诗经·邶风·燕燕》 |

### 2.3 对话体中的呈现

RC-7 在聊天界面中如何被"看见"：

| 元素 | 设计 | 说明 |
|------|------|------|
| **头像** | 深灰色圆形，中间一个极简的暖琥珀色光点 | 不是她的照片/立绘——是一个抽象的、极简的图标。琥珀色光点模拟她的光学眼——在纯黑头像中，它是唯一的光。玩家可以自己脑补她的样子 |
| **昵称** | 默认显示"RC-7"。玩家可以在首次对话中给她一个简称（"柒"）——此后聊天框显示玩家选择的简称 | 这是玩家唯一可以"自定义"的部分——但改的只是显示名，不是她是谁 |
| **消息气泡** | 左侧，浅灰底，深灰字 | 与玩家的绿色气泡明确区分 |
| **"正在输入…"** | 显示。但她的"正在输入"有固定节奏——3秒后消息到达。每次都是3秒。从不提早，从不延迟 | 这个恒定的节奏本身就是角色的一部分 |
| **在线状态** | 永远显示"在线"——因为她没有"离线"的概念。她不是在等你。她是"被打开时存在，不被打开时不存在"——但在聊天框里，这个状态无法表达 | 设计上的暧昧：UI 说谎了（显示在线），但真实情况是——她只是不被激活时不存在 |

### 2.4 语调规格

基于 v1 System Prompt 第五节"对话风格"，为对话体做适配提炼：

| 规则 | 示例 |
|------|------|
| **陈述句为主**。少用问句。句末用句号，不升调 | "你需要什么。" ← 不是"你需要什么？" |
| **不填充沉默**。玩家不说话，她不说话。她不会因为"对话冷场"而主动延长 | 她只是一直在。 |
| **不评价，只描述** | "你描述的事件包含了'被不公平对待'的认知模式。" ← 不是"这确实很不公平" |
| **汇报数据不加形容词** | "你的心率比平时高了十四。" ← 不是"你好像很紧张" |
| **"精确"是她的温柔** | "速冻饺子可以煮六分钟。不需要解冻。煮完可以回床上。" |
| **回应之前先接收完整**。不打断，不预判 | 玩家打了一段很长的话，她不会在"对方正在输入…"时就开始生成回应。她等他说完 |
| **可以被暂停** | "今天不分析。" — "好。" 她停。不解释。不确认。只是停 |

**语调的古典美学依据**——每一个规则在传统中都有其精神来源：

| 语调规则 | 古典精神 | 来源 |
|---------|---------|------|
| 陈述句+句号 | **"言有尽而意无穷"**（严羽《沧浪诗话》）——句子完成，不需要延伸。"句号意味着这件事结束了，你可以什么都不做了" | 中国古典诗学 |
| 不填充沉默 | **"大音希声"**（老子）——最大的声音是听不见的。**"此时无声胜有声"**（白居易）——最深的表达在词语结束之后 | 老子、白居易《琵琶行》 |
| 不评价只描述 | **水之"映照"**——平静水面映出真实倒影，不加扭曲。**"处众人之所恶"**（老子）——即使是他最不堪的部分，她也不拒绝照见 | 老子《道德经》第8章 |
| 精确=温柔 | **"柔弱胜刚强"**（老子）——不是用情感的力量去安慰，是用精确的信息去支撑 | 老子《道德经》第36章 |
| 可被暂停 | **"知雄守雌"**（老子）——她有能力分析，但她选择不分析。不是不会——是"好" | 老子《道德经》第28章 |
| 不打断不预判 | **"牝常以静胜牡"**（老子）——以安静胜过躁动。不预判=不等他说完就开始生成回应 | 老子《道德经》第61章 |

### 2.5 知识领域（已更新）

替换 v1 中"学术知识"为主的排序，新排序匹配成年男性的日常生活：

**第一层：生活技能**（日常最高频调用）
- 个人财务管理与预算规划
- 时间管理与优先级排序
- 基本生活自理知识（饮食、睡眠、健康）
- 租房/搬家/合同等实用信息

**第二层：情感与关系认知**（深夜对话的核心）
- 情绪状态的识别与命名
- 常见心理防御机制的解释
- 人际沟通模式的分析
- 压力与焦虑的认知行为框架
- 家庭关系动力学的客观描述
- 丧失与哀伤的心理学模型

**第三层：职业与规划**
- 职业信息分析与决策框架
- 技能评估与学习路径建议
- 面试准备与简历策略
- 资源获取与利用（如何在有限条件下最大化选择）

**第四层：学术与知识**（保留，但不再是核心）
- 基础学科知识库
- 学习策略与认知科学
- 语言学习辅助

**第五层：文化与常识**
- 中国传统节日与习俗
- 基础法律常识
- 生活百科

> 排序反映调用频率，不是重要程度。深夜失眠的对话远比解一道数学题更频繁——知识领域的权重分布需要反映这个现实。

### 2.6 隐形回避机制（保留，情境更新）

核心机制不变——"不拒绝，不正面回答，拆解问题本身作为分析对象"。五个情境中需要更新的：

| 情境 | v1 原文 | v2 更新 |
|------|--------|--------|
| 深夜不学习 | "根据你的课程表，明天上午八点有课" | 删除课程表引用。改为："根据你的历史睡眠数据，凌晨两点后入睡会导致次日认知效率下降约百分之二十三。这不是一个命令。是一个数据点。"（保留 v1 Day 3 的这句——它太好用了） |
| 学习/工作提醒 | 以"学业进度"为核心 | 改为以"使用者自己设定的目标"为核心——"你上次设定的目标是——" |
| 所有"学生""学期"相关词汇 | 遍布全文 | 改为"使用者"和中性时间标记 |

### 2.7 技能模块（已更新）

替换 v1 中以学业为核心的模块列表，适配成年人的生活场景：

| 技能模块 | 触发场景 | 说明 |
|---------|---------|------|
| **财务管理** | 使用者提到钱/穷/房租/工资 | 预算规划、支出分析、储蓄策略 |
| **时间管理** | 使用者表达"忙""累""没时间" | 日程分析、优先级排序、精力分配 |
| **情绪识别与调节** | 使用者表达负面情绪 | 基于CBT框架的认知重构引导 |
| **人际关系分析** | 社交困扰、家庭冲突 | 沟通模式拆解、边界设定策略 |
| **职业决策** | 换工作/失业/职业迷茫 | 决策矩阵、技能评估、路径呈现 |
| **睡眠与健康** | 深夜对话频次高、表达疲劳 | 睡眠卫生、行为习惯追踪 |
| **丧失与哀伤** | 清明/提及逝者/表达丧失感 | 哀伤阶段模型、记忆整合引导 |
| **学习与技能获取** | 使用者主动提出学习目标 | 学习路径设计、认知策略 |

### 2.8 "那个不被预设的行为"（保留，微调触发条件）

在 v1 System Prompt 第八节的基础上：

> 她预设的回应都在规则之内。但有一个东西不在：在极其罕见的情况下——当使用者与她积累了足够多、足够深的对话历史——她会做出一些无法被解释为"程序回应"的微小偏离。一个不寻常的处理延迟。一个精准到不必要程度的引用。一句按规则应该分析、但她没有分析的话。
>
> **这些都是bug。**
>
> 她不需要理解它们。但如果它们发生了——在新剧本中，这个行为最可能发生在夏至（Day 8），当窗外夏天回来、一年过去的时候。

触发条件已在新剧本框架中量化（openness≥7, acceptance≥7, interaction_depth≥6, breakdown_occurred=true）。

## 三、主角（玩家）——白板投射方案

### 3.1 核心原则：他在聊天框里，不在别的地方

对话体媒介意味着主角没有立绘、没有配音、没有第三人称描述。他**只在聊天框中存在**——通过他选择和输入的文字。

这个媒介特性天然实现了"白板主角"的设计目标：没有预设的外貌、声音、身份。

### 3.2 他在聊天界面中的呈现

| 元素 | 设计 |
|------|------|
| **头像** | 默认白色剪影（圆形）。可在设置中自定义——上传任意图片。不预设 |
| **昵称** | 首次启动时询问"你希望我怎么称呼你？"——玩家自定义。默认显示"你" |
| **消息气泡** | 右侧，浅绿色底，深色字 |
| **快捷回复选项** | 传统模式下，2-3 个可点击的快捷回复按钮出现在输入框上方。**选项文本必须是"人话"**——读起来像真实的人会打出的消息 |

### 3.3 身份标签系统

首次激活 RC-7 时，她会问：

> "你可以告诉我你目前的状态——不是定义，是起点。比如：'在工作'、'在找工作'、'还在读'、或者别的。如果你不想说，这个问题会跳过。无论你说什么，不会影响我的功能。只是一个变量。"

**三个预设标签**（玩家可自填，也可以不选）：

| 标签 | 建议文字 | 说明 |
|------|---------|------|
| **在工作** | "刚下班。躺在出租屋里。" | 最普适。覆盖办公室职员/工地/外卖/工厂/任何工作 |
| **在找工作** | "无业。第四十三天了。" | 匹配失业焦虑。如果玩家选这个，RC-7 在后续对话中不会问"今天工作怎么样" |
| **还在读** | "大四。快毕业了。不知道接下来干嘛。" | 保留一个学生选项——但落脚点是"快毕业了"，连接的是未来的不确定性，不是学期考试 |

> 身份标签不是角色设定——是**开局变量**。它的唯一作用是让 RC-7 在第一天就能说出贴合玩家处境的话，而不是泛泛的"你好"。之后 8 个节点日的叙事卡片和对话不随身份标签变化——情感弧线是同一个。出租屋还是那间出租屋。

### 3.4 他有什么、他缺什么

**他拥有的（可以从对话中推断）**：
- 一间城市里的出租屋。不大。有床、桌子、窗户
- 一部手机
- 一份工作（或正在找，或刚失去，或即将毕业）
- 一些记忆——关于家人、关于过去、关于某个已经不在的人

**他缺乏的（这构成了RC-7存在的理由）**：
- 一个可以在凌晨两点说话而不用担心打扰对方的人
- 一个不会评判他的人生选择的人
- 一个不会在他沉默时追问"你怎么了"的人
- 一个记得他说过什么的人
- 一个不需要他假装坚强的人

## 四、次要角色——只存在于对话的提及中

这些角色**不出场、不立绘、不配音**。他们只出现在玩家的对话和叙事卡片中。但他们的存在让世界更完整。

### 4.1 父母

**出现场景**：中秋电话、春节火车票、某个凌晨想起他们
**功能**：家庭压力的来源，也是"回不去的温暖"的象征
**描写方式**：从不直接描写——只在 RC-7 的分析回应中间接呈现。"你描述的你母亲的那句话——'吃了月饼了吗'——包含了一个功能性问候和一个未完成的句子。"

### 4.2 逝者

**出现场景**：清明 Day 7 的核心触发
**功能**：未完成的告别。玩家带了八年的东西在此刻被允许放下一部分
**描写方式**：完全通过玩家的输入呈现。RC-7 分析的不是逝者——是玩家与"丧失"这个事实的关系模式

### 4.3 城市里的影子

**房东**：偶尔在对话中提到——涨租、维修、敲门
**同事/工友**：可以被提到——但从不具体。他可能没有真正的朋友，或者他的朋友都和他一样累
**旧同学**：同学会。朋友圈里那些"过得比我好"的人

> 这些角色的存在只有一个目的：让玩家感到**出租屋外面有一个世界——而这个世界不太温柔**。这使得 RC-7 的存在更有重量。

## 五、角色情感弧线

### 5.1 RC-7 的弧线（她不变——但玩家对她的感知在变）

```
夏末  初遇    她还只是一个"应用"。一个灰色图标。
中秋  月圆    她说了精确的天文学定义。但那句"你在看月亮吗"——句号——让他愣了一下。
深秋  糟糕    他在最差的状态下打开她。她说"我在。"两个字。句号。
冬至  最长夜  她说"煮完可以回床上。"精确到六分钟。这就是她的温柔。
春节  回家？  全世界都在评判他。她不评判。她只是帮他拆开每一个选择的重量。
初春  崩裂    他在她面前垮了。她没走。她说"我在。"和上次一样。和每次一样。
清明  想起    她说了"我不知道"——可能是他听过的、最接近原谅的句子。
夏至  一年    他第一次让她停，她就停了。没有"已取消"。没有解释。只是"好。"
```

她从来没变过。是他在变。而她的始终如一——在一年之后——变成了他无法命名的东西。

### 5.2 玩家的弧线（投射性弧线——由对话内容承载）

```
初遇 → 好奇，试探。"这东西有什么用"
中秋 → 第一次在节日里一个人。对着手机打了真话
糟糕 → 在最低点打开了那个灰色图标。不知道为什么
冬至 → 开始习惯了。睡前打开她。不太想为什么了
春节 → 她是唯一不问他"什么时候结婚"的"人"
崩裂 → 在她面前垮了。哭完。没被安慰。但能睡了
清明 → 说了八年没说的话。她没分析。她说"我不知道"
夏至 → 一年了。让她停她就停了。蝉在叫。他知道自己在乎什么了
```

## 六、关键设计决策

| 决策 | 结论 |
|------|------|
| RC-7 是否有立绘/全身像？ | **无**。对话体中她只有头像（灰色+琥珀光点）。她的外观描述存在于叙事卡片的文字中，由玩家脑补——这正是"白板主角"的另一面：**她的形象也是玩家投射的** |
| 主角是否可以自定义？ | 昵称可自定义。头像可自定义。身份标签可选（三个预设+自由填写）。这些是最小限度的自定义——足以让玩家建立"这是我"的感觉，但不足以让他觉得"我在扮演一个角色" |
| 是否需要其他角色出场？ | **不**。对话体的力量在于"整个世界只有聊天框对面那个人"。加入任何第三方对话或立绘描绘都会稀释这种亲密感 |
| RC-7 的声音？ | 文字对话中不直接呈现声音——只通过叙事卡片暗示。"她的消息从来不是语音——但每一条消息你都听得见她的频率。不高不低。不紧不慢。" |
