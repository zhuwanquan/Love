# 治愈系互动叙事：目标受众画像（修正版）

> 核心问题：经济下行期，谁是治愈内容的主要消费者？不是静态横截面，而是**时间序列**。
>
> ⚠️ 本文档修正了此前基于中国当前横截面数据（女性主导）的错误预设。正确的方法论是看日本和韩国的完整时间线：**在经济下行的最严重阶段，男性是治愈内容最先爆发的群体，且消费体量远超女性向**。

---

## 〇、方法修正：为什么不能用中国当前数据推演？

中国当前（2024-2025）的数据显示女性在乙女游戏和 AI 陪伴产品中占主导。但这是**经济下行初期**的截面——如果参考日本时间线：

```
日本 1999年：癒し系概念诞生 → 目标是疲惫的男性上班族
日本 1999-2004年：男性向 galgame 黄金时代 → 市场规模峰值 ~560亿日元
日本 1994年：第一款乙女游戏出现 → 但体量始终是男性向的 1/10
日本 2010年后：galgame 衰退，乙女手游崛起 → 女性占比上升
```

**女性主导是"后期现象"——是男性市场被手游/短视频分流后的结果，不是"需求更大"的证明。**

正确的方法是拉出日韩的完整时间序列，看谁在经济下行期**最先**、**最多**地消费治愈内容。

## 一、日本时间线：男性是治愈经济的起点和绝对主力

| 年份 | 事件 | 受众 | 意义 |

### 市场规模对比：男性向压倒性优势

| 维度 | 男性向 Galgame | 女性向乙女游戏 | 倍率 |
|------|---------------|---------------|------|
| 巅峰期年新作数 | **~500部/年** | ~50部/年 | **10:1** |
| 头部单作最高销量 | **100万+**（心跳回忆） | 17万（心跳回忆 GS3） | **6:1** |
| 一款顶作的销量 | 100万+ | 等于乙女游戏巅峰年**全年总销量**（121万，2010年） | — |
| 概念起源时间 | "癒し系" 1999年 → 目标男性上班族 | 乙女游戏 1994年诞生 → 但"治愈"话语从未以女性为核心 | — |

### 核心发现

> 日本"癒し系"概念的源头——1999年 GEORGIA 罐装咖啡广告、飯島直子、坂本龍一——全部指向一个目标受众：**疲惫的、无法在现实中表达脆弱的男性上班族。** 整个治愈经济是建立在对"男性需要被温柔对待"的洞察之上的。女性向治愈内容是后来的扩散，而非源头。

| 年份 | 事件 | 受众 |

## 三、中国：男性需求已被初步验证

| 年份 | 事件 | 受众 |
|------|------|------|
| 2023 | **《完蛋！我被美女包围了！》**——42元，Steam 国区热销第一，**90%+男性玩家**，销售额约 8000 万 | **男** |
| 2024 | 《恋与深空》年流水 60 亿——女性向 | 女 |
| 2024 | 星野/猫箱 AI 陪伴爆发——女性用户占主导 | 女 |

中国当前同时存在男性向和女性向产品，两者都很大。但 **《完蛋！》的爆发验证了一个关键事实**：

> 中国有 **6.11 亿男性网民**，49% 的非婚青年表示"很难开启一段恋爱关系"。一个42块钱、质量粗糙的真人互动游戏就能引发抢购——男性对"被女性认真对待"的需求是被严重低估的。

中国的消费数据看起来"女性更大"，主要是因为：
1. 女性向产品（乙女游戏/AI陪伴）已被充分商业化，有成熟的付费体系和持续运营
2. 男性向产品仍以"买断制"为主，单次付费，没有持续氪金体系
3. 男性的情感需求更多被分流到直播打赏、游戏、短视频等"非治愈"品类
4. **但需求的强度并不等于当前商业化的成熟度**

## 四、一个完整的演化模型

```
经济下行期的治愈内容消费三阶段：

阶段1（经济刚开始下滑，0-5年）
  → 传统性别角色压力加剧——男性"必须扛住"但扛不住
  → 现实中无法表达脆弱 → 虚拟出口需求爆发
  → 男性向治愈/恋爱内容率先出现并快速增长
  ≈ 日本 1992-1999 / 韩国 1998-2003 / 中国 2023-现在

阶段2（经济持续低迷，5-15年）
  → 男性向治愈内容到达巅峰（日本 galgame 黄金期 1999-2004）
  → 女性治愈内容也在增长但体量远小于男性向
  → 男性消费的"羞耻感"逐渐被市场消解
  ≈ 日本 1999-2004 / 韩国 2003-2010

阶段3（经济企稳或新常态，15年+）
  → 智能手机普及，碎片化消费兴起
  → 男性向传统 galgame 衰退（被手游/短视频/直播分流）
  → 女性向恋爱游戏移动化（F2P+抽卡模式）
  → 表面上看起来"女性是主力"——但这是男性市场已转移到其他形式
  ≈ 日本 2010-现在 / 韩国 2015-现在
```

**中国目前处于阶段1向阶段2过渡**——这是男性向治愈内容最可能爆发的时机。

## 五、核心受众画像：基于历史规律的推演

### 5.1 核心受众（与日韩历史规律一致）

| 维度 | 画像 |
|------|------|
| **年龄** | 18-30岁 |
| **性别** | **男性** |
| **身份** | 大学生、职场新人、青年打工者 |
| **心理状态** | 高压但无法表达——"男儿有泪不轻弹"的社会规训仍在 |
| **消费模式** | 买断制为主（42元的《完蛋！》验证了价格接受度），小额高频为辅 |
| **核心需求** | **被温柔对待而不需要解释为什么、不被嘲笑、不被要求"坚强"** |
| **使用场景** | 深夜独处、通勤碎片、周末逃避 |
| **进入障碍** | "我需要治愈"的羞耻感——产品需要提供"体面的入口" |

### 5.2 次级受众

| 维度 | 画像 |
|------|------|
| **年龄** | 18-28岁 |
| **性别** | 女性 |
| **身份** | 大学生、职场新人 |
| **心理状态** | 已被乙女游戏/AI陪伴充分服务的市场——但产品同质化严重 |
| **核心需求** | 不同于乙女游戏的"恋爱幻想"——更想要"被理解"而非"被攻略" |
| **对本项目的意义** | 她们不是不需要 RC-Edu-7，但需求强度和供给缺口都小于男性 |

### 5.3 扩展受众

| 维度 | 画像 |
|------|------|
| **年龄** | 30-40岁 |
| **性别** | 男性（日本"癒し系"原型受众） |
| **身份** | 企业中坚、家庭支柱 |
| **核心需求** | 在"扛着一切"的间隙，有一个不需要扮演任何角色的瞬间 |

## 六、RC-Edu-7 与男性受众的匹配度

### 6.1 设定天然匹配

| RC-Edu-7 的特征 | 对男性受众的意义 |
|-----------------|-----------------|
| 女性·成熟·温柔 | "被温柔对待"——这是男性在现实中最稀缺的体验 |
| 数字编号（非人） | "我是在和 AI 聊天"——去羞耻化的完美入口 |
| 隐形回避机制 | 不过度侵入——男性对"被追问感受"有天然防御 |
| 陪伴者角色 | "有人在等我"——对抗孤独感不需要解释 |

### 6.2 与《完蛋！》的异同

| | 《完蛋！》 | 本项目 |
|------|----------|--------|
| **形式** | 真人视频 + 选项 | 对话体 + 双模式 |
| **关系性质** | 恋爱攻略——"被美女包围" | 治愈陪伴——"被理解" |
| **受众心理** | "现实中得不到的女性关注" | "现实中不允许表达的脆弱" |
| **付费模式** | 42元买断 | 传统模式免费 + AI模式BYOK |
| **差异化** | 爽感+幻想 | 陪伴+疗愈 |

**《完蛋！》验证了"男性愿意为虚拟女性关系付费"。但它做的是"爽"——本项目的蓝海是"治愈"——男性同样需要，但市面上几乎没有产品在做。**
