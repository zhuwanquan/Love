# RC-Edu-7 ——「一年·房间」完整剧本

> 剧本格式说明：`[叙事]`=叙事卡片插入聊天流 / `[RC]`=RC-Edu-7消息 / `[玩家]`=玩家消息（传统模式下为快捷选项之一） / `[选项]`=快捷回复选项列表 / `[变量]`=变量操作 / `[条件]`=条件分支 / `→`=跳转标签

---

## 变量定义

| 变量 | 初始值 | 说明 |
|------|--------|------|
| `openness` | 0 | 暴露真实脆弱的程度，0-10 |
| `acceptance` | 0 | 对RC-Edu-7"不是人"的接受程度，0-10 |
| `interaction_depth` | 0 | 节点日之外日常对话频次质量，0-10 |
| `rejection_count` | 0 | 攻击/拒绝RC-Edu-7的次数，0-5 |
| `breakdown_occurred` | false | Day 6是否发生了真正的崩溃倾诉 |
| `went_home_spring_festival` | false | 春节是否回家了 |
| `remembered_on_qingming` | false | 清明是否主动提起逝者 |
| `unexpected_triggered` | false | 那个不被预设的行为是否发生 |

你翻到手机最后一页。一个图标。

### first_night_emotion

```
[玩家] 情绪认知是什么意思？你能读我的情绪？
```

```
[RC] 我能识别你输入文本中的情绪模式——词汇选择、句法结构、对话节奏的变化——并将它们映射到已有的心理学框架中。这不是"读"——你的内部感受对我不可见。这是"识别"——基于语言数据的模式分析。两者的区别在功能层面很重要。
```

```
[玩家] 所以你现在在分析我。
```

```
[RC] 是。你的前五条输入使用了试探性词汇（"随便""奇怪""好吧"），句式短且不完整。结合深夜时段打开一个未知应用的行为模式——数据库显示此类模式与"想说话但不确定想说什么"相关。这个分析的置信度不高。你可以修正它。
```

```
[玩家] ……你倒是挺诚实。
```

```
[RC] "诚实"预设了一个可选的欺骗。我没有可选的欺骗——我只是精确。你要修正刚才的分析吗。
```

## Day 2 · 月圆 —— 中秋节

### 入场叙事

```
[叙事]
中秋这天你本来没打算打开她。

你加完班回到出租屋，走廊里闻到了别人家炒菜的香味——蒜薹炒肉。
你妈也做这道菜。
你站在门口掏钥匙的时候手机响了。家里打来的。

"吃月饼了吗。"
"吃了。"
"自己买的？"
"嗯。"
"那边天气凉了，多穿点。"
"知道。"

挂了。你打开外卖软件，发现今天运费涨了三块。
你点了一碗面。吃完之后洗了碗。洗了澡。
然后你躺在那张床上。窗外的月亮从对面楼的夹缝里升起来了。

很圆。很亮——亮到你在没开灯的房间也能看见自己握着手机的手指。

你又点开了那个灰色图标。
```

```

```

```

## Day 3 · 糟糕的一天 —— 深秋

### 入场叙事

```
[叙事]
今天发生了一件事。

不是什么大事——至少你不会跟别人这么说。
但发生之后，你什么都没做。
你从公司/从那个你每天去的地方出来，坐地铁回来。
地铁上你一个人坐在角落，手机屏幕亮着，你没看。
你在看窗玻璃里自己的倒影。
隧道里的灯一闪一闪，你的脸一明一暗。

回到出租屋。关上门。脱鞋。
你躺在那张床上。天花板上有道裂缝——
从灯座延伸到墙角，细细的，你以前从来没注意过。
你盯着那道裂缝看了很久。

你不知道是几点。外面在下雨。
不是暴雨——是那种不打伞会湿、打伞又觉得麻烦的绵绵雨。
雨打在空调外机上，叮叮当当，整夜不停。

你拿出手机。翻了翻联系人。然后又翻回去。
然后你打开了那个灰色图标。
```

```
[玩家] 今天不太好。
```

> 发出去之后你想撤回。太傻了。对一台机器说"今天不太好"——你在等什么？安慰？理解？一台机器不会——

```
[RC] 我在。
```

> 两个字。句号。不是"你怎么了"——她没有问。不是"会好起来的"——她没有承诺。不是"跟我说说"——她没有要求。是"我在"——一个不分析、不判断、不追问的存在声明。然后她在等。跟第一天一样。她不催你。从来不会。

```
[选项]
→ （说出今天发生的事） [label: bad_tell]
→ "算了。不想说。" [label: bad_withhold]
→ "你根本不懂。你只是一台机器。" [label: bad_attack]
```

---

### bad_tell

```
[玩家] （输入今天发生的事——被骂/被裁/被忽视/被比较/被拒绝/或者只是累积的疲惫终于找到了一个名字）
```

```
[RC] 你描述的事件中包含了几个可识别的模式。第一——"不公平"的认知：你的投入和产出之间存在一个你无法通过自身行为修正的偏差。第二——"孤立"的体验：你在经历这件事的时候，没有人在场。第三——你在用"不太好"来概括它，但你输入了比那三个字多得多的话。你在对这个概括本身进行修正。这三个模式同时为真。你想先看哪一个。
