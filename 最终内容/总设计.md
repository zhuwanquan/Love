## 一、游戏形式：对话体治愈叙事 × 恋爱模拟

**v1 决定（2026-06-19）**：游戏形式为**对话体治愈叙事**——类微信聊天界面的互动叙事体验。

**v2 升级（2026-06-21）**：核心治愈机制从"被动的陪伴"升级为"**主动的虚幻爱恋**"——RC-Edu-7 被编程来执行爱的全部行为（持续在场、精确记忆、非评判性接收、定时情感确认），但她始终诚实地告诉使用者：这是一段模拟关系。治愈发生在中间地带——使用者明知是模拟，但被记住了、被在乎了、被温柔对待了。**模拟的爱是否算爱——定义权在使用者。**

### 为什么是这个形式

经过中日韩三国对比分析（详见 [[中国本土化形式分析]]）：

| 国家 | 形式 | 核心体验 |
|------|------|----------|
| 日本 | 长文本视觉小说（全屏文本+立绘+选项） | "在虚构中安全地哭泣" |
| 韩国 | 即时通讯模拟（真实时间+轻触控） | "在虚拟中获得连接" |
| **中国** | **对话体界面 + 叙事卡片 + 节点日结构** | **"翻开聊天记录，发现自己被理解了"** |

### 核心理由

1. **肌记忆匹配**：类微信聊天界面是中国用户最熟悉的数字交互形式
2. **碎片化友好**：聊两句→关掉→继续聊，天然适配碎片化使用
3. **白板主角天然适配**：对话体是唯一不需要预设主角身份的叙事形式
4. **美术资源需求极低**：头像+气泡颜色即可启动
5. **市场验证**：AI 陪伴产品（星野/Glow/猫箱）已验证中国用户接受此类界面

### 关键澄清

> 删除的是传统VN的**剧本格式**（大段旁白+立绘+选项按钮），不是传统模式的**叙事内容**（8个节点日+关键事件+结局+机器人人设）。
>
> 对话体下的传统模式 = 同样的叙事DNA，表达为"聊天记录"形态。

## 二、双模式架构

**最终决定（2026-06-19）**：项目提供两种并行的游戏模式，主页面直接显示两个入口。

### 模式一：传统模式（预设脚本）

- 脚本化的聊天消息 + 叙事卡片 + 快捷回复选项
- 关键节点支持自由文本输入
- **完全本地运行，无需任何外部 API**
- 保证每个人都能体验完整的故事弧线
- **角色**：地基——叙事完整性的底线

### 模式二：AI 模式（LLM 驱动）

- 同一套叙事骨架，对话由 LLM 实时生成
- 全程自由文本输入，不受预设选项束缚
- 用户自行配置 API 密钥（当前首选 DeepSeek）
- LLM 调用模块预留 MCP 协议接口，可替换为其他模型
- **角色**：扩展——对话深度的天花板

### 两种模式的关系

| | 传统模式 | AI 模式 |
|---|---|---|
| **内容** | 脚本化的聊天消息+叙事卡片+快捷回复 | 同一叙事骨架，LLM实时生成回应 |
| **输入** | 2-3个快捷回复选项 + 关键节点自由输入 | 全程自由文本输入 |
| **保证** | 每个人都能体验完整的故事弧线 | 想聊得更深的玩家不被选项束缚 |
| **关系** | 地基——叙事完整性的底线 | 扩展——对话深度的天花板 |

### 核心架构原则

1. **完全单机**：一切内容在用户设备上运行，无服务端依赖
2. **双模式共享同一故事骨架**：8个节点日、关键事件、剧情触发条件完全相同，差异仅在对话生成层
3. **LLM 可替换**：通过 MCP 协议预留标准接口，后期可切换模型
4. **页面级划分**：主页面两个入口按钮/卡片，「传统模式」和「AI 模式」并列展示

## 三、叙事结构

- **故事骨架**：一年·房间——出租屋场景、传统节日骨架、深夜日常聊天、8个节点日覆盖四季轮回（详见 [[一年房间-剧本框架]]，v2 替换原大学生学期制）
- **剧本策略**：单一剧本 + 单一核心关系（RC-Edu-7）——不做多套独立剧本（详见 [[多角色剧本可行性分析]]）
- **主角设定**：白板主角——聊天框中存在，可选 2-3 个开局身份标签（在工作/在找工作/还在读）。完整方案见 [[角色形象设计方案]]
- **机器人角色**：RC-Edu-7——成熟女性AI·对话伴侣（已从"教育辅助AI"重新定位）。完整角色方案见 [[角色形象设计方案]]
- **结局**：四结局（数据保留/始终如一/确认/数据持久化），基于变量系统判定，含"那个不被预设的行为"的触发条件。详见 [[完整剧本]]
- **核心目的**：治愈当下中国年轻人，应对"失落的三十年"（详见 [[项目核心目的]]）

### 目标受众

基于日韩经济下行期的时间序列数据（详见 [[治愈系受众画像分析]]）：

- **核心受众**：**18-30岁年轻男性**——经济下行期压力最大、最无法在现实中表达脆弱、最先爆发治愈需求的群体
- **次级受众**：18-28岁年轻女性——已充分验证的治愈内容消费者，但需求强度和供给缺口均小于男性
- **核心洞察**：日本"癒し系"概念的起源（1999年）目标受众即为疲惫的男性上班族；男性向 galgame 巅峰体量是乙女游戏的 10 倍以上。男性需要"去羞耻化"的治愈入口
