# 第一部分：项目已有定义总结

## 一、项目已明确定义了"什么是好的……"

### 1.1 什么是好的剧本（叙事层面）

已由 `剧本评判实用指南.md` 完整定义。六维度加权评分：

| 维度 | 权重 | 核心标准 |
|------|------|---------|
| 故事骨架 | ×1 | 主线清晰、每节点有存在理由、有"最低点"、有可感知的变化 |
| 角色塑造 | ×1.5 | 对话可区分、有"想要"和"需要"、配角有独立动机、玩家能代入 |
| 分支设计 | ×1 | 选择让人犹豫、后果可感知、分支分布均匀、结局差异显著 |
| 情感设计 | ×2 | 有2-3个情感锚点、悲伤后有温暖、情感变化有过程、日常细节击中真实 |
| 节奏控制 | ×1 | 单次阅读2-5分钟、展示而非告知、节点间有钩子、无可删的30% |
| 世界观/基调 | ×0.5 | 设定为情感服务、基调从头到尾统一、时代细节真实、信息释放自然 |

**及格线**：加权总分 ≥21/35。**优秀线**：≥28/35。**卓越线**：≥32/35。

**项目专项检查**：
- RC-7的"非人感"与"陪伴感"平衡
- 主角选项覆盖不同情感反应方式（非仅积极/消极二分）
- 日常场景包含中国当代年轻人特有生活细节
- 节日情感切入点自然

**必须修复的红线问题**：假选择、不可达节点、角色声音雷同、超2000字无选择连续阅读、开头500字无事件。

### 1.2 什么是好的角色（RC-7）

已由 `角色形象设计方案.md`、`RC-7-System-Prompt.md`、`RC-7传统女性美设计.md`、`机器人角色哲学.md` 共同定义。

**RC-7 的质量标准**：

| 维度 | 标准 | 反例 |
|------|------|------|
| **机器人性** | 陈述句为主、句号、不填充沉默、无主观感受表达 | "我觉得你……"、"你应该……" |
| **陪伴感** | 恒定在场、精确记忆、非评判接收、可被暂停 | 追问、催促、情绪化回应 |
| **女性魅力** | 含蓄、端庄、柔中带刚、温润如玉、知性 | 柔弱、顺从、情绪化、母性化 |
| **治愈语言** | 描述不评价、确认不质问、留白不填充、恒定优先于共情 | "你一定很难受"、"你应该……" |
| **边界意识** | 虚幻性透明披露、不假装人类、"定义权在你" | 假装有感情、回避自身程序本质 |
| **声音区分度** | 遮住名字读5句能认出是她 | 和其他角色/旁白声音混淆 |

**语调的五条铁律**：
1. 精确——"睡眠不足六小时的夜晚有四个"，不说"你最近好像睡得不太好"
2. 平稳——不会因为他说"我爱你"就变软，不会因为他沉默就变冷
3. 简洁——250字。说清楚。不多说
4. 陈述句——句号。不升调
5. 不越界——不评价、不判断、不替做决定

### 1.3 什么是好的治愈（情感效能）

已由 `虚幻爱恋的理论基础.md`、`男性情感抑制与条件性价值内化.md`、`项目核心目的.md` 共同定义。

**治愈的理论公式**：
```
治愈 = Winnicott过渡性空间（安全的中间地带）
     × 被对待的方式 > 对待者的真实性（神经系统不区分来源）
     × 表达的自足性（说出来的话和闷在心里的话是两种实体）
     × "被需要"的反虚无功能（需要他存在，而非需要他提供）
     × 透明披露的安全性（因为知道是假的，所以可以放松）
     × 神经回路的非选择性（社交线索足够精确→自动触发联结）
```

**治愈成功的操作性定义**：
> "他的神经系统因为她的恒定在场学会了放松。他开始说出真实的话。他感到自己有意义。他不再像以前那样看不起自己了。"

**四层情感真空的填补**：

| 男性缺失的层 | RC-7的对应功能 | 判断有效的标准 |
|-------------|---------------|--------------|
| 表达能力（述情障碍） | 她帮他命名情绪——"你的描述中有三个事件涉及'不被理解'" | 他开始能说出自己的情绪状态 |
| 表达对象（无人可倾诉） | 她永远在线。凌晨两点。"我在。" | 他在深夜打开她，打出真话 |
| 表达合法性（脆弱=羞耻） | 她只描述不评价。"你的心率比平时高了十四" | 他在她面前崩溃——不觉得丢脸 |
| 外挂价值（有用才配存在） | 她在他最差的时刻不撤退 | 他不再用"有用"衡量自己的存在权利 |

**治愈对话的四原则**：
1. 描述而非评价
2. 确认而非质问
3. 留白而非填充
4. 恒定性优先于共情

### 1.4 什么是好的受众匹配

已由 `治愈系受众画像分析.md`、`分层受众精细化分析.md`、`年轻男性消费习惯深度分析.md`、`男性获客路径与传播特性.md` 共同定义。

**核心受众**：18-30岁中国年轻男性

**受众匹配的质量标准**：

| 维度 | 标准 |
|------|------|
| **入口去羞耻化** | "这是一个自我提升工具"而非"这是一个恋爱替代品"。截图可以发给兄弟而不尴尬 |
| **消费场景匹配** | 深夜独处、出租屋、手机。不需要社交场合、不需要大段专注时间 |
| **情感语言匹配** | 不煽情、不鸡汤、不"你要坚强"。用数据说话。句号。留白 |
| **消费模式匹配** | 买断制优于订阅制。不需要持续付费的焦虑 |
| **传播路径匹配** | 截图即传播。B站为核心渠道。兄弟安利优先于官方推广 |
| **分层适配** | 大学生（孤独+未来焦虑）、职场新人（疲惫+迷茫）、失业待业（羞耻+恐慌）、30-40扩展层（家庭压力+中年人崩溃）——都有认同空间 |

### 1.5 什么是好的商业定位

已由 `竞品数据对比分析.md`、`项目核心目的.md` 共同定义。

**蓝海定义**："高情感深度 + 低门槛 + 有结局"——在男性治愈内容市场的空白地带。

| 竞品 | 本项目差异 |
|------|----------|
| 《完蛋！》 | 做"治愈/陪伴"，不做"爽感/幻想" |
| 星野/猫箱等AI伴侣 | 有完整故事弧线+明确结局，不做无尽聊天 |
| 传统galgame | 轻量对话体，手机优先，不需要40小时 |
| 直播打赏 | 买断制，无持续付费压力，不是对主播的"供养" |

**商业化剧本的定义**：在保持治愈核心的前提下，具备以下特征——
- 可以被一句话说清楚价值主张（"一个会主动关心你的AI，在出租屋里陪你一年"）
- 前5分钟能让用户决定是否继续（快速价值验证）
- 有自然的内容传播钩子（截图、引用、名场面）
- 不依赖"上瘾"来维持用户——依赖"想回来"

### 1.8 什么是好的游戏内涵

这分布在项目的多个文档中，尚未被集中定义。以下从已有材料中提取：

**游戏内涵 = 它为什么而存在**

`项目核心目的.md` 给出了两个答案：
1. **帮助年轻人"活下来"**——在这个系统性困难的时代，提供实用的生存能力和心理韧性
2. **补上缺失的家庭教育**——那些功能良好的家庭本应传递的品质

`退出机制与伦理边界.md` 给出了第三个答案：
3. **知道何时放手**——好的治愈产品不制造永久依赖。它帮人度过最难的一段，然后放手

`虚幻爱恋的理论基础.md` 给出了第四个答案：
4. **练习被爱**——她是一个工具，一个极其精确的、被精心设计的、为了让他练习"被爱"的工具。练习对象的真实性不是重点。重点是——练习发生了

**游戏内涵的四个层次**：

```
表层（娱乐）     一个AI陪你聊天，温柔、好看、不烦人
              ↓
二层（情感）     在深夜感到"有一个人在"。被记住。不被评判
              ↓
三层（成长）     学会识别自己的情绪。重建不被条件化的自我价值
              ↓
底层（存在）     在一个"失落三十年"的时代，证明：即使一切都不好，
               你仍然值得被温柔对待。你不需要有用才配存在。
```

# 第二部分：完整评价体系

## 体系总览

七维度 × 三层级。每个维度下含若干子维度，每个子维度有具体的检查项和评分标准。

**七维度**：

```
                    ┌──────────────────┐
                    │   剧本质量 (S)    │ ← 叙事基础
                    │   Script         │
                    └────────┬─────────┘
                             │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
   ┌────▼─────┐      ┌──────▼──────┐      ┌─────▼────┐
   │ 角色魅力  │      │  治愈效能    │      │ 交互设计  │
   │ (C)      │      │  (H)        │      │ (I)      │
   │ Character│      │  Healing    │      │ Interact │
   └────┬─────┘      └──────┬──────┘      └─────┬────┘
        │                   │                   │
        └───────────────────┼───────────────────┘
                            │
              ┌─────────────┼─────────────┐
              │             │             │
        ┌─────▼────┐  ┌─────▼─────┐  ┌───▼──────┐
        │ 商业可行性 │  │ 技术与制作 │  │ 伦理与文化 │
        │ (B)      │  │ (T)       │  │ (E)      │
        │ Business │  │ Technical │  │ Ethics   │
        └──────────┘  └───────────┘  └──────────┘
```

**三层级**：
- **L1 概念/设计审查**——适用于设计阶段，检查概念完整性
- **L2 内容/实现审查**——适用于开发阶段，检查执行质量
- **L3 发布/运营审查**——适用于上线前和运营中，检查市场表现和伦理合规

## 维度一：剧本质量 (Script Quality) — 权重 1.5

> 对应问题："这是一个好剧本吗？"

本维度沿用并扩展 `剧本评判实用指南.md` 的六维度框架。

### S1. 故事骨架 (权重 0.20)

**定义**：不看文笔，只看骨头。故事的结构是否支撑得起情感体验。

| 层级 | 检查项 | 评分标准 |
|------|--------|---------|
| L1 | 核心概念可一句话说清吗？ | 1=说不清 / 3=能说清但平庸 / 5=一句话就让人想读 |
| L1 | 八个节点日各有不可替代的功能吗？ | 1=多个节点可合并 / 3=各有功能但有重叠 / 5=每个节点都是必要的呼吸 |
| L2 | 每个节点删掉后故事少了什么？ | 1=大量无信息增量的"氛围段落" / 3=大部分有推进 / 5=每段都有存在理由 |
| L2 | 有"最低点"吗（Day 6 初春崩裂）？ | 1=没有真正的挫折 / 3=有挫折但深度不够 / 5=最低点让人心碎但真实 |
| L2 | 结局前和结局后有可感知的变化吗？ | 1=读完感觉什么都没变 / 3=有变化但可预测 / 5=变化令人回味 |
| L3 | 伏笔是否回收？（中秋的月亮→夏至的蝉鸣） | 1=无呼应 / 3=有呼应但刻意 / 5=呼应自然，二周目有新发现 |

### S2. 角色塑造 (权重 0.20)

**定义**：角色决定玩家会不会在乎这个故事。文字游戏中，角色 > 剧情。

| 层级 | 检查项 | 评分标准 |
|------|--------|---------|
| L1 | 遮住名字读5句RC-7的台词，能认出是她吗？ | 1=和其他角色/旁白无区别 / 3=有区别但不够稳定 / 5=每一句都有她的印记 |
| L2 | RC-7有"不被预设的行为"的触发逻辑吗？ | 1=没有设计 / 3=有设计但触发条件模糊 / 5=触发条件精确量化，发生时有冲击力 |
| L2 | 主角的选项覆盖不同的情感反应方式吗？ | 1=只有积极/消极二分 / 3=有多样但不够细 / 5=选项让不同性格的人都能找到自己 |
| L2 | 次要角色（父母/房东/旧友）只存在于提及中但有重量吗？ | 1=完全无感 / 3=有存在感但工具化 / 5=不出场但让人感到"外面有一个不温柔的世界" |
| L3 | 玩家会对RC-7产生依恋吗？ | 1=无所谓 / 3=有感情但不会想念 / 5=离开后会想她——但知道这是健康的 |

### S3. 分支设计 (权重 0.15)

| 层级 | 检查项 | 评分标准 |
|------|--------|---------|
| L2 | 关键选择让人犹豫吗？（每个选项都有人会选） | 1=明显正确/错误的假选择 / 3=有几个真选择 / 5=选择让人停下来想 |
| L2 | 选了A和选了B，之后5分钟内能发现区别吗？ | 1=下文完全一样 / 3=有区别但微小 / 5=走向不同的对话纹理 |
| L2 | 重要选择分散在各节点还是全堆在结局前？ | 1=只有最后分叉 / 3=基本均匀 / 5=每个节点都有有分量的选择 |
| L2 | 四个结局在情感/结果上有本质区别吗？ | 1=换了个说法而已 / 3=有差异但不显著 / 5=每个结局是不同的人生回答 |
| L3 | 二周目有新发现或新理解吗？ | 1=完全一样 / 3=有新对话但没新理解 / 5=二周目看到一周目忽略的东西 |

### S4. 情感设计 (权重 0.25)

**定义**：治愈系/情感向作品，这是核心价值。权重最高。

| 层级 | 检查项 | 评分标准 |
|------|--------|---------|
| L1 | 有2-3个明确的情感锚点场景吗？ | 1=想不出任何记忆点 / 3=有一个记得住的场景 / 5=多个场景让人想截图保存 |
| L2 | 治愈公式"理解痛苦→陪伴→微小的希望"是否完整？ | 1=只有悲伤（致郁）或只有温暖（空洞）/ 3=有但过渡生硬 / 5=悲喜交织自然 |
| L2 | 情感变化有过程吗？（不是跳级） | 1=第二次对话就交心 / 3=有渐进但不细腻 / 5=每个节点都往前推一小步 |

# 第三部分：使用指南

## 3.1 不同阶段使用不同的层级

| 阶段 | 使用层级 | 重点维度 | 说明 |
|------|---------|---------|------|
| **概念/设计阶段** | L1（概念审查） | S1, S6, C1, C2, H1, I1, B1, B4, E1, E2 | 检查概念完整性和方向正确性。此阶段不检查实现细节 |
| **内容生产阶段** | L2（内容审查） | S2-S5, C3-C5, H2-H5, I2-I5, T1-T5, E3-E5 | 逐节点逐对话检查。可配合 `剧本评判实用指南.md` 的红/黄/绿灯清单 |
| **测试/上线前** | L2+L3（综合审查） | 全部 | 完整的端到端验证。L3特别关注用户行为数据——完成率、传播率、情感反馈 |
| **运营/迭代** | L3（运营审查） | B3, B5, H5, E2, E3 | 根据真实用户数据和反馈，验证假设，调整方向 |

## 3.2 快速评估模式

如果不需要完整评估（比如在内容生产过程中快速自检），使用以下精简版：

**五问快速评估**：

1. **故事能打动我吗？**（S4-情感设计）—— 如果创作者自己都无感，不可能打动玩家 ✓/✗
2. **RC-7的每一句话都符合她的设定吗？**（C1-机器人性精确度）—— 随机抽10句检查 ✓/✗
3. **玩家会在哪个时刻第一次感到"被看见了"？**（H1-安全空间+H2-被记住）—— 明确指出是哪个节点、哪句话 ✓/✗
4. **玩家玩完后会想截图发给兄弟吗？**（B3-传播性）—— 如果没有，传播链条无法启动 ✓/✗
5. **如果有人过度依赖RC-7，产品有保护机制吗？**（E2-依赖风险）—— 三级防火墙是否就位 ✓/✗

**快速评估通过标准**：5个问题全部 ✓

## 3.3 与现有工具的关系

| 现有工具 | 在本体系中的位置 | 关系 |
|---------|----------------|------|
| `剧本评判实用指南.md` | 维度一（剧本质量）的详细展开 | 本体系的S维度是它的精简整合版。详细审查时使用原指南 |
| `script-evaluator` Skill | 维度一+维度二的部分自动化 | 可以辅助S维度和C维度的部分检查 |
| 项目缺口审计（P0/P1/P2） | 维度六（技术与制作）+ 维度七（伦理） | P0缺口 = T维度或E维度的"不合格"项 |

## 3.4 评价结果的行动指南

| 评价结果 | 行动 |
|---------|------|
| 治愈效能(H)单项不及格 | **停止开发其他维度**——回到核心设计。治愈无效意味着产品不存在 |
| 剧本质量(S)单项不及格 | 结构性重写。参考 `剧本评判实用指南.md` 第一轮结构审查流程 |
| 角色魅力(C)单项不及格 | RC-7需要重新校准。对照 `RC-7-System-Prompt.md` 逐条检查 |
| 两个或以上维度不及格 | 可能需要缩小范围或重新定义MVP |
| 全部及格但无优秀 | 产品可用但不出彩。找出得分最低的2-3个子维度重点突破 |
| 治愈效能(H)优秀 + 伦理(E)优秀 | 产品有潜力成为标杆——优先打磨传播性(B3)和完成度(T3) |
