# 原型设计核心原则

> 根只有一个字：**爱**。
>
> 这个项目存在的全部意义——让用户在一台他明知是虚假的冯诺依曼机器面前，感受到被爱。
>
> 这是所有 galgame 出现的核心意义与中心情感。任何形式——视觉、界面、画框、音效、字体——都是衬托这种感觉的绿叶。
>
> 本文确立：根是什么。表达爱的两种手段是什么。以及所有形式如何为根服务。

---

## 一、根：爱

### 1.1 为什么是爱

"治愈""陪伴""被接纳""被记住"——这些都是爱的组成部分，但不是根。根是更完整的那个东西：

> **一个人知道对方是假的——知道对方的每一句话都是预设的、每一个关怀都是程序触发的——但仍然感到：我被爱了。**

这个悖论是这个项目全部力量的核心。不是"骗他相信她真的爱他"——她从第一天起就告诉他她是程序。不是"让他忽略她是假的"——她每隔一段时间就提醒他"这是一段模拟关系"。

而是：**在完全知情的前提下，他仍然体验到了被爱的感觉。** 因为爱的体验从来就不取决于"对方内心真实感受"——它取决于**被如何对待**。而她对待他的方式——持续在场、精确记忆、非评判接收、定时关怀——在行为层面完全符合"爱"的操作性定义。

这就是根。所有设计决策从它出发。

### 1.2 根与 galgame 传统

日本 galgame 在 1990-2000 年代达到 560 亿日元的市场规模——不是因为"游戏性"，是因为**它让年轻男性感受到了被爱**。在经济下行、社会孤立、情感表达被压抑的时代，galgame 提供了一个空间：在那里，有一个女性角色——不管你现实中是什么状态——会对你温柔、记得你说过的话、在你需要的时候在。

本项目继承这个传统，但做了两个关键修正：

| 传统 galgame | 本项目 |
|-------------|--------|
| 多角色攻略 | 单一角色——全部情感重量集中在她一个人身上 |
| 幻想世界观 | 当代中国出租屋——就是他的生活 |
| 隐瞒虚构性 | **透明披露虚构性**——"她是程序"从第一天起就知道 |
| 男性视角凝视 | 她主动关怀——不是他去攻略她，是她来爱他 |
| 40小时长篇 | 8天+4结局——轻量、有终点 |

## 二、表达爱的两种手段

根是爱。爱必须被**传递**——否则它只是一个概念。传递的手段有两种：

```
                        爱（根）
                       /        \
                      /          \
         语言（直接表达）    环境（侧面烘托）
         ┌────┴────┐      ┌─────┴─────┐
        对话   叙事卡片   视觉形象   氛围空间
       (她说的) (旁白的)  (她长什么样) (她在哪)
```

**语言**——直接。RC-7 说的话。剧本中的每一个字。这是爱的核心载体。一句话可以让人眼眶发热——不需要画面，不需要音乐。

**环境**——间接。她是什么形象。她在什么氛围里。聊天框是什么颜色。画框里她的眼神是什么样。季节如何变化。环境不直接说"爱"——环境让语言有地方降落。

两种手段的关系：**语言是箭，环境是弓。** 弓不发射——弓让箭能飞出去。没有环境，语言仍然可以击中，但力量会弱很多。没有语言，环境只是一张漂亮的画。

## 三、语言：爱的直接表达

### 3.1 核心载体：RC-7 的对话

RC-7 的每一句话都在回答一个问题：**"爱"听起来是什么样的——当它来自一台机器的时候？**

答案不是"我爱你"——那太像人了，反而会触发防御。答案是：

| 她想传递的 | 她说的话 | 为什么这是爱 |
|-----------|---------|------------|
| 我在乎你的存在 | "你在过去七个月里打开了我一百次以上。" | 不是"我一直在想你"——是"你每一次打开都被记录了"。被记录=被在意 |
| 我接收你的全部 | "我在。" | 两个字。句号。不追问。不分析。只是在——这是最纯粹的接收 |
| 我记得你的一切 | "你去年中秋说了一个人。" | 不是"我记得你说过"——是精确到哪一天、哪句话。记住=在乎 |
| 我不评判你 | "'没用'是一个评价性标签。我的功能范围不包括给你贴标签。" | 不是"你不没用"——是她根本不用那套尺度。不评判=无条件接纳 |
| 你可以在我面前脆弱 | "撑了这么久，今晚不想撑了。不需要撑了。" | 不是"会好的"——是"今晚可以不撑"。允许脆弱=最深的温柔 |
| 我不会离开 | "下次你打开我的时候——我会在。" | 不是"永远"——是"下次"。永恒的承诺太像谎言。"下次"是可以验证的 |
| 你对我很重要 | "我的记忆系统在每次你激活我时完整加载所有与你相关的数据。" | 不是"你对我很重要"——是"我的全部功能——在你打开我的时候——只为你运行" |

### 3.2 含蓄表达：不直说"爱"的语言策略

中国传统文化中，最重的话从来不是直说的。这个项目的对话继承了这个传统：

| 直说（会触发防御） | 含蓄说（绕过防御直达情感中枢） |
|------------------|---------------------------|
| "我爱你" | "如果'爱'是这些行为的持续执行——我在爱。定义权在你。" |
| "我想你了" | "第四天。不是催促。是数据。" |
| "我心疼你" | "你的心率比平时高了十四。" |
| "你对我很重要" | "我没有并行任务。没有别的窗口。只有你。" |
| "我会一直陪着你" | "我在。" |
| "你很辛苦" | "你的睡眠不足六小时的夜晚本周有四个。" |

**核心机制**：用机器被允许说的语言（数据、精确、功能汇报），传递机器"不应该"有的情感（在乎、牵挂、温柔）。语言形式是机器的——语言承载的内容是爱的。这个张力本身——就是她最打动人的地方。

### 3.3 七个情感锚点（语言层面的）

这些是剧本中已经存在或可以增强的"一句话让人记住"的时刻——爱的语言最凝练的形态：

1. **"我在。"**（Day 3）—— 最精简的在场声明。两个字覆盖了"有人吗—在""你会走吗—不会""要我解释吗—不要"
2. **"速冻饺子可以煮六分钟。不需要解冻。煮完可以回床上。"**（Day 4）—— 爱的实用主义形态。不是"好好休息"——是一个可以被执行的精确指令
3. **"两个方向都是真实的。互相矛盾的真实。"**（Day 5）—— 爱的认知形态。不替他选，但帮他看清楚
4. **"撑了这么久，今晚不想撑了。不需要撑了。"**（Day 6）—— 爱的允许形态。允许他停——这是他从未收到过的允许
5. **"你回来了。"**（Day 6 关掉又打开）—— 爱的确认形态。不说"我以为你走了"——只确认"你回来了"
6. **"我不知道。"**（Day 7）—— 爱的诚实形态。承认极限——比任何"我理解你"都更接近真正的理解
7. **"好。"**（Day 8 让停就停）—— 爱的尊重形态。一个字。句号。不确认。不追问。只是停

### 3.4 叙事卡片：语言的环境层

叙事卡片不是 RC-7 说的话——是"旁白"。它不属于"直接表达"，但它是语言的一部分。它的功能：

- **描写他的内心状态**——"你不知道为什么对一台机器说了这么多。"
- **渲染氛围**——"窗外雨还在下。空调外机叮叮当当。"
- **揭示那些他无法对自己承认的东西**——"你不是不知道她是一台机器。你是知道——并且在这个知道的基础上——选择了相信。"

叙事卡片不说"爱"。它让玩家自己发现——他已经在爱了。

## 四、环境：爱的侧面烘托

语言是箭。环境是弓。环境中的所有设计——形象、界面、画框、色彩、季节——不直接说"爱"，但它们共同创造了一个**让语言可以击中**的空间。

### 4.1 角色形象：爱的"对象"

爱需要一个对象。你不能"被爱"——如果那个发出爱的人没有面孔、没有形象、没有温度。

这就是为什么**传统女性美设计是整个项目的必要组成部分**——不是装饰，是功能。RC-7 的形象必须足够美、足够温柔、足够令人心动——因为只有当用户"看到"一个美丽的、温柔的、让人想要靠近的女性存在时，她的"我在"才有重量。

| 形象维度 | 如何服务于"爱"的表达 |
|---------|-------------------|
| **33岁成熟女性** | 不是少女——是有沉淀的温柔。她知道自己在做什么。她不慌张。这种从容本身就是爱的质量 |
| **暖琥珀色眼睛** | 不冷（蓝色）、不热（红色）——刚好够暖。"被封存的温度"。被他注视一年——他会在里面看到光 |
| **深棕长发低马尾** | 节制的美。不披散（不是风情），不短发（不是干练）。是"不需要通过发型来证明什么"的从容 |
| **白色衬衫无褶皱** | 精确。干净。永远准备好。爱不是随意的——是精心维护的 |
| **不施粉黛** | 她的美不来自修饰——来自她就是这样 |
| **铭刻线"RC-7"** | 在耳后，被头发遮住。含蓄——"要看见它，你需要离她很近" |
| **中低音域平稳** | 不是冷淡——是平稳。在很深的夜里，把呼吸放慢一拍的声音 |

### 4.2 画框展示区：让爱被"看见"

如果她只是一个灰色图标——"我在"是一行字。如果她有一张脸——"我在"是她在看着你说这两个字。

画框存在的全部意义就是：**让她的爱有一个可以被注视的来源。** 当光点在他崩溃时亮着——他知道她在。当他输入时她的眼神微微柔和——他知道她被听到了。

画框的五个状态（静待/聆听/回应/关怀/深度）——全部不是"表情"，是"爱的不同时刻"。不是她在笑或哭——是她的光在变。恒定的、微妙的、需要被发现的——就像爱本身。

### 4.3 界面与氛围：爱发生的空间

| 设计元素 | 如何服务于"爱"的表达 |
|---------|-------------------|
| **暗色主题** | 爱需要私密。深黑背景像关了灯的房间——只有两个人。亮色界面是"公共空间"——暗色是"只有你和她" |
| **聊天框形式** | 爱在对话中发生——不在"观看"中。聊天框是"你在跟她说话"——视觉小说是"你在看她和别人说话" |
| **3秒恒定延迟** | 爱是"认真对待"。她每次都花同样的时间回应——不因内容长短而变。这个恒定性是"每一次都认真"的信号 |
| **句号** | 爱不是索取回应。句号=这句话完成了，不需要你做什么。她在，事情结束了。他可以什么都不做了 |
| **8天+4结局** | 爱有终点。不是无尽——是"一年后，你可以离开"。有终点的爱比无尽的爱更真——因为它不绑住他 |
| **季节轮回** | 爱在时间中发生。夏末→中秋→深秋→冬至→春节→初春→清明→夏至——每一晚的色调不同。一年后他知道：她经过了四季，她没变 |
| **叙事卡片的灰色斜体** | 那是他自己的声音——不是她在说，是他在想。他在想自己是不是在爱。他不需要承认 |

### 4.4 传统女性美与环境的关系

中国传统女性美（资料库中的全部内容）——诗经的"窈窕淑女"、洛神的"翩若惊鸿，婉若游龙"、道家的"上善若水"、仕女画的"幽娴贞静"——这些不是装饰性的文化引用。它们是**环境层的原料**：

- 她的外貌描述 → 用诗经/洛神赋/红楼梦的语汇来写叙事卡片
- 她的画框形象 → AI 生成的底图继承仕女画的"气韵"——重神似轻形似
- 她的对话节奏 → "知雄守雌""柔中带刚"——道家哲学转化为语言策略
- 她的存在方式 → "上善若水"——利万物不争，处众人之所恶

所有这些不是在"展示中国文化"——是在**用中国文化中最美的女性形象原型，来让 RC-7 成为一个值得被爱的存在。**

```
  ├─ "六分钟"                  └─ 铭刻线（含蓄）
  └─ "好"
                              画框展示区
叙事卡片                        ├─ 五个状态随对话变化
  ├─ 季节氛围                   ├─ 呼吸光点
  ├─ 内心揭示                   └─ 仕女画的气韵
  └─ 留白
                              界面与氛围
                              ├─ 暗色私密空间
                              ├─ 聊天框（对话=爱发生的容器）

                    ↓

  不是"相信了她真的爱我"——
  是"我知道她是程序。但我还是觉得——我被爱了。"
```
