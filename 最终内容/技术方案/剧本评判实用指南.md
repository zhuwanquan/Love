# 文字游戏剧本评判实用指南

> 面向非文学专业创作者，避免抽象术语，每一条都能直接对照检查。
> 适用于：对话体治愈叙事 / 视觉小说 / Galgame 类文字游戏

---

## 快速自测：三句话判断剧本方向对不对

在深入细节之前，先用这三个问题快速过一遍：

| # | 问题 | 通过了才算方向对 |
|---|------|-----------------|
| 1 | 你能用一句话说清楚"这是一个关于什么的故事"吗？ | 不能 = 核心概念不清晰 |
| 2 | 玩家/读者在故事结束后，会记住哪一个瞬间？ | 想不出 = 缺乏情感锚点 |
| 3 | 如果把所有分支删掉只剩一条线，故事本身还好看吗？ | 不好看 = 剧本骨架有问题，分支救不了 |

---

## 一、六维度评判体系

每条维度评分 1–5 分（1=严重问题，5=出色），总分 30 分。**15 分及格，21 分良好，25 分以上优秀。**

### 维度 1：故事骨架（剧情/结构）

**不看文笔，只看骨头。**

| 检查项 | 怎么看 | 常见问题 |
|--------|--------|---------|
| **开头 5 分钟有钩子吗？** | 读前 500 字，读完想继续吗？ | 开头全是世界观说明，没有事件 |
| **每个节点都在推进什么？** | 逐节点问：删掉这段，故事少了什么？ | "氛围描写"太多，没有信息增量 |
| **冲突/张力够不够？** | 有"玩家想知道接下来怎样"的时刻吗？ | 太平淡，角色一直和谐相处 |
| **结局前有"最低点"吗？** | 主角有没有经历一次真正的挫折？ | 一路顺遂，缺乏情感起伏 |
| **结局有变化吗？** | 故事的起点和终点，主角/关系发生了可感知的改变 | 读完感觉"然后呢？什么都没变" |

**具体评分标准：**

| 分数 | 标准 |
|------|------|
| 1 | 故事线混乱，不知道在讲什么，读完无感 |
| 2 | 有一条主线但松散，中间有大段无事发生的部分 |
| 3 | 主线清晰，有明显的起承转合，但部分节点空洞 |
| 4 | 结构完整，每个节点都有存在理由，节奏得当 |
| 5 | 结构精妙，伏笔回收、前后呼应、节奏张弛有度 |

---

### 维度 2：角色塑造（人物/对话）

**角色决定玩家会不会在乎这个故事。文字游戏中，角色 > 剧情。**

| 检查项 | 怎么看 | 常见问题 |
|--------|--------|---------|
| **每个角色说话能区分吗？** | 遮住名字，读 5 句台词，能分辨是谁说的吗？ | 所有角色说话一个腔调 |
| **主角有"想要"和"需要"吗？** | 想要=表层目标，需要=深层缺失（主角自己不一定意识到） | 主角只是事件的旁观者 |
| **对话像人话吗？** | 大声读出来，像正常人会说的话吗？ | 对话成了"交代信息的工具"，不像聊天 |
| **配角有独立动机吗？** | 配角的存在是为了服务主角，还是有自己的逻辑？ | 工具人——只在对主角有用时才出现 |
| **主角让玩家能代入吗？** | 玩家能不能在主角身上看到自己？ | 主角太具体（职业/性格/经历过于限定）或太空洞 |

**具体评分标准：**

| 分数 | 标准 |
|------|------|
| 1 | 角色脸谱化，对话无法区分，没有代入感 |
| 2 | 有一两个角色有特点，但整体扁平，对话信息功能过重 |
| 3 | 主要角色有辨识度，对话基本自然，有基础动机 |
| 4 | 角色立体，对话有个人风格，动机清晰，有成长弧线 |
| 5 | 角色令人难忘，对话精彩，情感真实，玩家会产生依恋 |

---

### 维度 3：分支设计（选择/后果）

**分支不是越多越好。10 个无关痛痒的选择 < 2 个真正重要的选择。**

| 检查项 | 怎么看 | 常见问题 |
|--------|--------|---------|
| **选择有"让我犹豫"的感觉吗？** | 每个选项是否都有人会选？ | 一个明显正确 + 一个明显错误 = 假选择 |
| **选择后果能被感知到吗？** | 选了 A 和选了 B，之后 5 分钟内玩家能发现区别吗？ | 选了不同选项，下一段对话完全一样 |
| **关键分支分布均匀吗？** | 重要选择是分散在各处，还是全堆在结局前？ | "伪非线性"——前面只有一条路，最后才分叉 |
| **有"信息分支"吗？** | 有的选项不是改变剧情走向，而是让玩家了解不同信息 | 所有选项都是"去A地/去B地"式的路线选择 |
| **结局差异够明显吗？** | 不同结局在情感/结果上有本质区别，而不是换了个说法 | 结局只是"好感度数字不同，文案差不多" |

**具体评分标准：**

| 分数 | 标准 |
|------|------|
| 1 | 线性，没有实质选择，或者选择没有后果 |
| 2 | 有选择但大多不影响剧情（假分支），关键分支只在最后 |
| 3 | 有几个有意义的选择，分支分布基本合理 |
| 4 | 选择有分量，分支分布均匀，不同路径体验有明显差异 |
| 5 | 选择令人纠结，分支自然融入叙事，多周目体验丰富 |

---

### 维度 4：情感设计（情绪/共鸣）

**治愈系/情感向作品，这个维度权重加倍。**

| 检查项 | 怎么看 | 常见问题 |
|--------|--------|---------|
| **有没有"情感锚点"场景？** | 有没有 2-3 个让玩家情绪波动的关键场景？ | 全程情绪平稳，没有高峰 |
| **悲伤之后的温暖够不够？** | 治愈系的核心公式：理解痛苦 → 陪伴 → 微小的希望 | 只有悲伤（致郁），或只有温暖（空洞） |
| **情感变化有过程吗？** | 角色关系是逐步升温，还是突然就亲密了？ | 跳级——第二次见面就交心 |
| **细节有没有击中日常？** | 有没有能让玩家说"对，我也是这样"的日常细节？ | 场景太特殊，普通人没有类似经历 |
| **情绪节奏有起伏吗？** | 紧张→舒缓→紧张→舒缓，有呼吸感 | 一直高强度情感输出，玩家麻木 |

**具体评分标准：**

| 分数 | 标准 |
|------|------|
| 1 | 情绪平铺直叙，没有起伏，无法引起共鸣 |
| 2 | 有一两处情绪点但力度不够，或节奏失控 |
| 3 | 有明显的情绪高峰和低谷，能引起基础共鸣 |
| 4 | 情绪节奏精准，有多个有效情感锚点，治愈力强 |
| 5 | 击中内心，读完有被理解和陪伴的感觉，余味悠长 |

---

### 维度 5：节奏控制（篇幅/信息密度）

**文字游戏的致命伤：玩家阅读速度远超作者预期，无聊就关掉了。**

| 检查项 | 怎么看 | 常见问题 |
|--------|--------|---------|
| **每个节点长度合适吗？** | 单次阅读 2-5 分钟（约 500-1500 字），超过就切 | 一个节点 3000 字，玩家疲劳 |
| **信息是"展示"还是"告知"？** | "他很伤心" vs "他盯着屏幕，很久没说话" | 大量的内心独白和情感说明 |
| **节点之间有"钩子"吗？** | 每次结束一个节点，有没有让玩家想继续的东西？ | 节点在"自然停顿点"结束，没有悬念 |
| **有没有"可删的 30%"？** | 尝试删掉每个节点 30% 的文字，故事受影响吗？ | 大量的修饰词和重复表达 |
| **日常对话有推进吗？** | 日常场景中，对话是在展示角色/推进关系，还是单纯寒暄？ | "早上好""吃什么""晚安"式的无信息对话 |

**具体评分标准：**

| 分数 | 标准 |
|------|------|
| 1 | 篇幅失控，大量冗余，阅读疲劳感强烈 |
| 2 | 有明显的水分，部分节点信息密度低 |
| 3 | 篇幅基本合理，有可优化的空间但不算拖沓 |
| 4 | 节奏紧凑，信息密度适中，读起来流畅不累 |
| 5 | 每段都有存在理由，长短交替有呼吸感，停不下来 |

---

### 维度 6：世界观与基调（设定/氛围）

**治愈系的重点不是设定多复杂，而是"氛围对了吗"。**

| 检查项 | 怎么看 | 常见问题 |
|--------|--------|---------|
| **设定与情感目标一致吗？** | 世界观是为情感服务的，还是为了炫设定？ | 设定很复杂但与主线情感无关 |
| **基调从头到尾统一吗？** | 开头的语调和结尾的语调是同一个世界的吗？ | 开头治愈，中间突然变悬疑/恐怖 |
| **时代/场景细节真实吗？** | 玩家能不能通过细节感知到"这是真实的生活"？ | 场景像舞台布景，缺乏生活质感 |
| **有"这个世界特有的"细节吗？** | 有没有只有在这个设定下才能发生的情节？ | 换一个世界观故事完全一样 |
| **信息释放自然吗？** | 世界观是逐步渗透的，还是开头一大段说明？ | 开场 5 分钟全是背景介绍 |

**具体评分标准：**

| 分数 | 标准 |
|------|------|
| 1 | 世界观混乱或与故事脱节，基调不统一 |
| 2 | 有基本设定但不够融入叙事，有出戏感 |
| 3 | 设定与故事基本协调，氛围大体对路 |
| 4 | 设定自然融入叙事，细节有生活质感，基调统一 |
| 5 | 世界令人沉浸，细节真实可感，氛围精准 |

## 二、针对你的项目：治愈系对话体的专项检查

基于你的 RC-7「一年·房间」项目特点，额外增加这几条：

### 机器人角色专项

- [ ] RC-7 的对话中，机器人的"非人感"和"陪伴感"平衡吗？（太像人=失去特色，太像机器=没有温度）
- [ ] 它的回应是否体现了"理解但不评判"的定位？
- [ ] 有没有它"不像机器人会说"的台词？（比如过于情绪化的人类表达）
- [ ] 它的知识领域（生活+情感前置）在对话中有自然地体现吗？

### 白板主角专项

- [ ] 主角的反应/选项是否足够"空"，让不同玩家都能代入？
- [ ] 主角的选项是否覆盖了不同的情感反应方式？（不只是"积极/消极"二分）
- [ ] 主角有没有被动感太强的问题？（全是机器人在主动，主角只是在回应）

### 日常场景专项

- [ ] 日常场景中是否包含"中国当代年轻人特有的生活细节"？（外卖、租房、加班、过年回家……）
- [ ] 节日节点的情感切入点是否自然？（不是"因为今天是XX节所以伤感"，而是"因为发生了XX，今天恰好是XX节"）
- [ ] 深夜聊天场景中，对话是否有"深夜特有的坦诚感"？

### 变体复用检查（多角色版本）

- [ ] 切换机器人身份/主角职业时，哪些节点需要重新写，哪些可以共享？
- [ ] 共享节点的对话是否足够通用，不会在某个变体中出戏？

## 三、实操流程：如何改自己的剧本

### 第一轮：结构审查（只看骨架）

1. 把每个节点用一句话概括，写在卡片上
2. 把卡片按顺序排列
3. 问自己：
   - 有没有两卡卡片在说同一件事？（合并或删除）
   - 有没有节点删掉后完全不影响理解？（删除）
   - 情感曲线长什么样？（画出来：横轴=节点，纵轴=情绪强度）

### 第二轮：朗读测试（对话检查）

1. 把所有对话大声读出来
2. 标记所有"读起来别扭"的地方
3. 检查：遮住角色名，能分辨谁在说话吗？

### 第三轮：分支遍历（检查选择质量）

1. 画出分支树
2. 标记每个选择节点的选项数量和后果
3. 检查：有没有"假选择"（选了不同选项但下文一样）？
4. 检查：有没有"废结局"（玩家不可能到达的结局）？

### 第四轮：他人试读（最关键的检验）

1. 找一个没看过剧本的人读
2. 观察但不干预：哪里停下来？哪里跳过？哪里表情有变化？
3. 读完后问三个问题：
   - 你觉得这是一个关于什么的故事？
   - 你最喜欢/最不喜欢哪个部分？
   - 有什么地方让你觉得困惑或出戏？

## 四、可以使用的外部工具

### IntelliVNG MCP Server（技术向）

- **是什么**：基于 MCP 协议的视觉小说脚本分析工具
- **能做什么**：自动检测孤立节点、死胡同、分析分支分布、计算非线性分数
- **怎么用**：需要 Node.js 环境，输入 JSON 格式的节点数据
- **适合谁**：有一定技术能力的开发者
- **获取**：`npm install @intellivng/mcp-server`
- **局限**：需要把剧本转成结构化 JSON，对纯文本剧本不能直接分析；目前版本 0.1.0，功能仍在完善中

### Twine + Story Validator（半技术向）

- **是什么**：Twine 的交互叙事验证工具
- **能做什么**：自动遍历所有叙事路径，检测不可达段落、结局分布、变量变化
- **适合谁**：愿意用 Twine 来搭建剧本结构的创作者

### 最简单的方法：用 AI 辅助审查

你可以把剧本片段喂给 Claude 或类似 AI，使用以下 prompt 模板：

```
请用以下标准评估这段文字游戏剧本：

1. 对话是否自然？（大声读出来像人话吗）
2. 角色是否可区分？（遮住名字能分辨谁在说话吗）
3. 这一段推进了什么？（删掉它，故事少了什么）
4. 情感是否有层次？（不是只有一种情绪）
5. 有没有"不像这个角色会说"的台词？

请给出具体指出问题的位置和改进建议，不要抽象的文学批评。
```

## 五、速查清单：提交前的最终检查

在认为剧本"写完"之前，逐条过一遍：

### 必须修复（红灯）
- [ ] 存在"假选择"（选了不同选项下一段文字完全相同）
- [ ] 存在不可达的结局/节点
- [ ] 有角色说话腔调完全一样
- [ ] 有超过 2000 字无选择点的连续阅读段
- [ ] 开头 500 字内没有任何事件发生

### 建议修复（黄灯）
- [ ] 关键分支全集中在最后 1/3
- [ ] 缺少"最低点"情感场景
- [ ] 日常对话中有无信息量的寒暄段
- [ ] 配角纯粹工具化
- [ ] 结局之间差异不显著

### 加分项（绿灯）
- [ ] 有 2-3 个明确的情感锚点场景
- [ ] 存在"信息分支"（不是为了改变走向，而是揭示不同侧面）
- [ ] 日常细节有当代中国生活质感
- [ ] 多周目有新的发现/理解
- [ ] 读完有"余味"

## 六、评分快速参考卡

| 维度 | 权重 | 1分 | 3分 | 5分 |
|------|------|-----|-----|-----|
| 故事骨架 | ×1 | 混乱无主线 | 主线清晰有起伏 | 伏笔回收结构精妙 |
| 角色塑造 | ×1.5 | 脸谱化无区分 | 有辨识度有动机 | 令人难忘产生依恋 |
| 分支设计 | ×1 | 无实质选择 | 几个有效选择 | 纠结自然多周目丰富 |
| 情感设计 | ×2 | 无起伏无共鸣 | 有高峰低谷基础共鸣 | 击中内心余味悠长 |
| 节奏控制 | ×1 | 大量冗余 | 基本合理 | 停不下来 |
| 世界观/基调 | ×0.5 | 与故事脱节 | 基本协调 | 沉浸精准 |

> 治愈系作品**情感设计权重翻倍**，因为这是核心价值。
> 加权总分 = 故事×1 + 角色×1.5 + 分支×1 + 情感×2 + 节奏×1 + 世界观×0.5
> 满分 35 分，21 分及格，28 分良好，32 分以上优秀。

---

*最后一条建议：好剧本是改出来的，不是写出来的。第一稿的任务是"写完"，第二稿之后才是"写好"。用这份指南在第二稿之后开始检查，不要在写第一稿时边写边审。*
