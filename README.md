# RC-7：教育机器人互动叙事游戏

## 项目核心

一款 AI 驱动的互动叙事游戏。玩家扮演一名中国大学生，与一台教育用 AI 机器人 **RC-7** 在一个学期内建立关系。

**创作目的**：治愈当下中国年轻人——在即将面临"失落的三十年"的时代背景下，通过一个不会主动关心你、但永远精确回应的存在，补上那些缺失的家庭教育所未能传递的东西。

## 目录结构

```

  核心设定/        机器人 System Prompt、项目目的、角色哲学

  技术方案/        LLM 互动架构、故事压缩与字数限制
过程内容/          被替代的旧版本（System Prompt v1、旧主角设定等）
素材组件/          参考模板、废弃的原始剧本框架
项目管理/          实现路线图
```

## 核心机制

- **主角**：白板——玩家自定义，自由文本输入
- **机器人**：冯诺依曼架构——无主观能动性，1与0的隐喻。通过 LLM API + 固定 System Prompt 驱动
- **故事结构**：学期制节点日——8个节点日，之间以固定叙事过渡
- **对话限制**：玩家输入 ≤150 字，机器人输出 ≤250 字，单次会话 ≤20 轮
