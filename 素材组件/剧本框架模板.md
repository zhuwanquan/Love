# 剧本基础框架

## 一、核心要素

| 要素 | 说明 |
|------|------|
| **主题** | 一句话说清故事要探讨什么 |
| **前提** | 一个"如果……会怎样"的高概念设定 |
| **主角** | 有明确缺陷与欲望的人物 |
| **对手** | 不仅是反派，是主角欲望的阻碍力 |
| **弧线** | 主角从 A 状态到 B 状态的转变轨迹 |

---

## 二、三幕结构

**第一幕：建置（约 25%）**

- 日常世界 → 主角的现状、缺陷、欲望
- 激励事件 → 打破平衡，改变一切
- 第一幕转折 → 主角做出不可逆的选择，进入新世界

**第二幕：对抗（约 50%）**

- 上升行动 → 一连串越来越难的障碍
- 中点转折 → 重大胜利或惨败，赌注升级
- 黑暗时刻 → 一切都似乎失败了，主角跌入谷底

**第三幕：解决（约 25%）**

- 最后转机 → 新认知或新力量出现
- 高潮 → 与对手的最终对决，主题的终极检验
- 结局 → 建立新平衡，展现主角的改变

---

## 三、节拍表（Blake Snyder 简化版）

1. **开场画面** — 故事世界的第一印象
2. **主题呈现** — 暗示故事要讲什么
3. **铺垫** — 主角的缺陷与缺失
4. **催化剂** — 打破旧世界的事件
5. **纠结** — 主角犹豫、抗拒
6. **进入第二幕** — 跨过门槛
7. **B 故事** — 副线（通常是情感线）启动
8. **娱乐与游戏** — 概念最吸引人的部分
9. **中点** — 伪胜利或伪失败
10. **反派逼近** — 压力增大
11. **一无所有** — 黑暗时刻
12. **灵魂暗夜** — 主角顿悟
13. **进入第三幕** — 带着新方案回来
14. **结局** — 旧世界被改造，新平衡确立
15. **终场画面** — 与开场画面形成对照

## 四、单场剧本格式（标准格式）

```
[场景标号] 内景 / 外景 — 地点 — 时间（日/夜）

[动作描写：场景氛围、人物动作，用现在时]

        角色名
            对白内容

（括号内：简要情绪/动作指示）

[转场说明：切至 / 淡出 / 叠化]
```
