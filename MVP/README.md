# RC-Edu-7 MVP 原型

## 快速启动

```bash
# 1. 进入 MVP 目录
cd MVP

# 2. 安装依赖
npm install

# 3. 设置 API Key（二选一）
# 方式A：创建 .env 文件
cp .env.example .env
# 然后编辑 .env，填入你的 Anthropic API Key
# 方式B：启动后在页面弹窗中输入

# 4. 启动服务器
npm start

# 5. 打开浏览器
# http://localhost:3000
```

## 测试内容

MVP 运行的是 **Day 1「激活」**场景：
- 场景文本展示（首次激活 RC-Edu-7）
- 15 轮自由对话
- 达到上限后展示退出过渡文本

## 当前限制

- 会话存储在服务器内存中（重启后丢失）
- 无长期记忆系统（每轮对话独立）
- 仅支持单日场景（Day 1）
- 界面未适配移动端

## 测试要点

测试时关注以下方面：
1. RC-Edu-7 是否严格遵循 System Prompt（不主动发起、隐形回避、250字限制）
2. 对话是否自然流畅
3. 角色一致性是否在 15 轮内保持
4. 情感张力是否自然浮现（不刻意煽情）
